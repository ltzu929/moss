# 游戏内容规范

> 游戏内容相关决策的判断标准 + 决策记录区。

---

## 判断标准

检查AI给的内容方案时，逐项问这些问题：

| 检查项 | 说明 | 通过标准 |
|--------|------|----------|
| **玩家是否有选择感？** | 选项是否真的有差异，不是假选择 | 不同选项有明显不同后果 |
| **后果是否可预期？** | 玩家能不能大致猜到选择的后果 | 后果与选项描述有逻辑关联 |
| **情感是否到位？** | 文本是否符合MOSS冷AI的设定 | 读起来像MOSS说的话 |
| **和世界观一致吗？** | 内容是否符合流浪地球设定 | 不与已知设定矛盾 |
| **有没有后续影响？** | 这次选择会不会影响后续事件/结局 | 有跨事件的连锁影响 |

---

## 使用方式

1. AI给出内容方案后，用上方表格逐项检查
2. 每项都要能回答"通过"
3. 有不通过的项，让AI重新调整方案
4. 全部通过后，写入下方记录区

## 决策记录区

### 世界观资料层级

**决策日期**：2026-05-03

**最终方案**：电影主线 + 原著补充。电影明确事件作为第一版硬锚点，原著用于补充地下城、地表环境、粮食压力与长期航行情绪。项目原创事件只作为游戏桥接内容，不伪装成电影情节。

**选择理由**：电影事件能保证玩家认知稳定，原著细节能补足策略叙事所需的日常压迫感和灾难质感。

**相关约束**：第一版本时间范围为2044-2075；第一版本只做MOSS阵营。

**相关约束**：`data/events/` 顶层 `.tres` 会自动加载，备选事件不得留在活动目录。

### 2065 AI隔离审查事件

**决策日期**：2026-05-03

**最终方案**：联合政府要求限制MOSS核心权限，玩家在“配合隔离审查”“有限开放接口”“隐藏核心链路”之间选择。

**选择理由**：这是MOSS主线桥接事件，能把电影危机之间的长期AI治理矛盾显性化，并为阶段五的MOSS日志提供情感冲突。

**相关约束**：目标板块为“联合政府”；不新增隐藏数值；当前只通过秩序、希望、控制权、能源表现后果。

### 2070西伯利亚发动机群过载事件

**决策日期**：2026-05-03
