# UI交互规范

> UI相关决策的判断标准 + 决策记录区。

---

## 判断标准

检查AI给的UI方案时，逐项问这些问题：

| 检查项 | 说明 | 通过标准 |
|--------|------|----------|
| **信息是否清晰？** | 玩家一眼能看懂这是什么、有什么用 | 不需要说明文字 |
| **操作是否直观？** | 不需要说明就能知道怎么操作 | 第一次就能正确操作 |
| **反馈是否及时？** | 点击/操作后有没有即时反馈 | 操作后立即有视觉/声音反馈 |
| **有没有视觉层次？** | 重要信息是否突出，次要信息是否弱化 | 能一眼区分重要/次要 |
| **和已定UI风格一致吗？** | 和现有UI的配色、布局风格是否统一 | 放在一起不违和 |

---

## 使用方式

1. AI给出UI方案后，用上方表格逐项检查
2. 每项都要能回答"通过"
3. 有不通过的项，让AI重新调整方案
4. 全部通过后，写入下方记录区

### 事件选项按钮样式

**决策日期**：2024-04-25

**最终方案**：方案C（终端/控制台风格）

**样式描述**：
- 背景：半透明黑色 `rgba(0, 0, 0, 0.5)`
- 边框：左侧4px青色边框 `#8BDDD9`，其余1px深青色 `#236164`
- 字体：等宽字体（Consolas / Godot monospace）
- 前缀：">" 提示符，强化AI身份认知

**状态反馈**：
- hover：背景变亮，边框发光，">"闪烁
- pressed：背景加深，边框变亮青色 `#00ffcc`
- 禁用：整体灰度，边框灰色，文字灰色

**效果显示**：
- 正面效果用绿色 `#6bff6b`
- 负面效果用红色 `#ff6b6b`
- 能源消耗用黄色或青色

**选择理由**：
1. 完美契合MOSS设定，强化"你是AI"的身份认知
2. 简洁不干扰阅读，让信息成为焦点
3. 与流浪地球电影MOSS界面风格一致
4. 与项目现有深青色背景风格统一

**参考文件**：`docs/ui-mockup/event-button-styles.html`

**相关约束**：主界面深青色背景、MOSS冷AI设定
