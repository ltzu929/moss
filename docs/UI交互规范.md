# UI交互规范

> UI相关决策的判断标准 + 决策记录区。

---

## 判断标准

检查AI给的UI方案时，逐项问这些问题：

| 检查项 | 说明 | 通过标准 |
|--------|------|----------|
| **信息是否清晰？** | 玩家一眼能看懂这是什么、有什么用 | 不需要说明文字 |
| **操作是否直观？** | 不需要说明就能知道怎么操作 | 第一次就能正确操作 |
| **反馈是否及时？** | 点击/操作后有没有即时反馈 | 操作后立即有视觉/声音反馈 |
| **有没有视觉层次？** | 重要信息是否突出，次要信息是否弱化 | 能一眼区分重要/次要 |
| **和已定UI风格一致吗？** | 和现有UI的配色、布局风格是否统一 | 放在一起不违和 |

---

## 使用方式

1. AI给出UI方案后，用上方表格逐项检查
2. 每项都要能回答"通过"
3. 有不通过的项，让AI重新调整方案
4. 全部通过后，写入下方记录区
