# MOSS模拟器 - UI布局优化设计

> 日期：2026-04-15
> 状态：已批准，待实现

---

## 一、设计目标

优化游戏界面布局，解决以下问题：
- 右上角资源栏位置不明显
- 右侧大量空白浪费
- 缺少MOSS状态显示区域
- 年份进度没有可视化
- 视觉层次感不足

---

## 二、核心决策

### 2.1 整体布局

**方案A2：网格布局**

```
┌─────────────────────────────────────────────────┐
│ 顶部状态栏                                        │
│ MOSS-550C | 算力100 | 能源100 │   [年份进度条]    │
├───────────────────────────────────┬─────────────┤
│                                   │             │
│   板块网格区（2列）                │  MOSS状态    │
│                                   │  面板        │
│   ┌─────┐  ┌─────┐                │             │
│   │亚洲 │  │北美 │                │  - 型号     │
│   └─────┘  └─────┘                │  - 进化进度 │
│   ┌─────┐  ┌─────┐                │  - 控制权   │
│   │UEG  │  │欧洲 │                │             │
│   └─────┘  └─────┘                │             │
│                                   │             │
├───────────────────────────────────┴─────────────┤
│ 底部：指令按钮栏                                  │
│        [算力分配] [系统接管] [进化]               │
└─────────────────────────────────────────────────┘
```

**优点**：
- 板块卡片大小一致，视觉整洁
- 进度条一目了然
- 2列网格，支持未来5-7个板块扩展
- 右侧MOSS状态区有独立空间

---

### 2.2 年份进度条

**简洁进度条样式**

```
2044 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 2075
      ▼ 当前年份标记
```

位置：顶部状态栏右侧

---

### 2.3 控制权显示

**进度条样式**，和板块属性进度条统一风格：
- 颜色：红色（#ff4444）
- 高度：18px
- 显示百分比数字

---

### 2.4 板块选中样式

**金色边框高亮**（后期可调整）
- 边框颜色：#ffd700
- 边框宽度：3px
- 标题文字变为金色

---

### 2.5 指令按钮

**冷却显示**：进度条覆盖在按钮上
- 可用状态：正常显示
- 冷却状态：半透明黑色覆盖层，中央显示"冷却中 X年"

**消耗信息**：按钮内显示核心 + hover显示完整
- 按钮内："算力分配 | 消耗20"
- Hover tooltip：显示完整信息（效果、冷却时间等）

---

### 2.6 事件弹窗

**选项显示后果预览** + hover显示详细描述

```
┌──────────────────────────────┐
│        太空电梯危机           │
│          2044年              │
│  数字生命派发动袭击...        │
│                              │
│  ┌──────────────────────┐   │
│  │ 紧急救援              │   │  ← hover显示描述
│  │ ✓希望+15 ✓秩序+5      │   │
│  │ ✗算力-20             │   │
│  └──────────────────────┘   │
│                              │
│  ┌──────────────────────┐   │
│  │ 信息封锁              │   │
│  │ ✓秩序+10             │   │
│  │ ✗希望-5 ✗算力-10     │   │
│  └──────────────────────┘   │
└──────────────────────────────┘
```
