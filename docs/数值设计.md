# 数值设计

> 数值相关决策的判断标准 + 决策记录区。

---

## 判断标准

检查AI给的数值方案时，逐项问这些问题：

| 检查项 | 说明 | 通过标准 |
|--------|------|----------|
| **玩家能否理解？** | 数值是否直观，是否需要额外解释 | 不需要教程就能理解 |
| **有没有边界情况？** | 数值会不会出现负数、溢出、死循环 | 所有边界都有处理 |
| **成长感是否合理？** | 从初期到后期，数值变化是否有节奏感 | 有明显的阶段性变化 |
| **容错空间够不够？** | 玩家犯错后有没有恢复的机会 | 至少有2次以上的容错 |
| **和已定数值兼容吗？** | 新数值和已确定的数值体系是否冲突 | 不产生矛盾或覆盖 |

---

## 使用方式

1. AI给出数值方案后，用上方表格逐项检查
2. 每项都要能回答"通过"
3. 有不通过的项，让AI重新调整方案
4. 全部通过后，写入下方记录区
