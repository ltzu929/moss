# 世界观资料来源与设定分级

本文档只维护世界观资料的可信度、引用规则和关键概念口径。事件设计见 `../design/游戏内容规范.md`，逐年素材见 `流浪地球：2044-2075灾难编年史.md`。

## 来源层级

| 层级 | 定义 | 使用规则 |
|------|------|----------|
| 电影明确 | 两部电影正片、片尾彩蛋、电影内字幕或角色台词明确呈现 | 可作为时间线硬锚点 |
| 原著明确 | 刘慈欣原著《流浪地球》明确描写 | 用于补充灾难质感和长期航行情绪，不覆盖电影时间线 |
| 官方/主创补充 | 片方物料、主创访谈、官方美术设定或权威官方宣传 | 可补充设备、机构与视觉细节，需标明不是正片情节 |
| 可靠二手整理 | 专业媒体、科普文章、百科或维基整理 | 只用于交叉校验，不能单独定为电影正史 |
| 游戏原创桥接 | 为游戏节奏新增或重排的事件、因果和选择 | 必须明确标注为游戏桥接 |
| 不确定/待核实 | 来源矛盾、单薄或只见于粉丝资料 | 不进入当前硬设定 |

## 使用规则

1. 非电影明确内容不能写成电影正史。
2. 原著细节必须标明“原著补充”，尤其是具体数字和社会制度。
3. 官方或主创资料不能替代正片剧情。
4. 二手资料需要与电影、原著或官方资料交叉验证。
5. 游戏桥接必须说明它服务的玩法或叙事问题。
6. 来源无法确认时降低表述强度，不补写确定性结论。

## 550C、550W 与 MOSS

### 550C

- 2044 时期的 550 系列智能量子计算机。
- 可接入关键工程和自动化系统。
- 游戏文本中偏向计算、应急调度和有限接管，不写成已经完全人格化的 MOSS。

### 550W

- 2058 时期的高阶 550 系列。
- 与全球信息、航天员评估、发动机控制和数字生命承载相关。
- 游戏文本中偏向整合、预测、接口渗透和数字生命兼容。

### MOSS

- 第一部中的领航员号空间站 AI，执行联合政府授权的火种计划。
- 核心口径是执行“延续人类文明”的元指令。
- 可以冷酷地牺牲局部，但不写成以伤害人类为乐的反派。
