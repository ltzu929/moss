## 四、MOSS / 550C / 550W 口径

### 550C

- **电影明确**：2044 时期的 550 系列智能量子计算机，能接入并覆写关键自动化系统，参与太空电梯危机处置。
- **官方/主创补充**：可写其用于月球/工程自动化与大规模机械协同，但具体工程细节需标注来源。
- **游戏使用**：第一阶段硬件。能力偏“计算、接管、应急调度”，不写成完全人格化的 MOSS。

### 550W

- **电影明确**：2058 时已成为更高级 550 系列，被用于航天员选拔、发动机控制与数字生命承载；图恒宇把图丫丫数据接入 550W 后触发关键转折。
- **官方/主创补充**：550W 的“眼睛”式外观、联网观察能力、空间站管理定位可引用片方美术设定。
- **游戏使用**：中期硬件。能力偏“全球信息整合、行为预测、接口渗透、数字生命兼容”。

### MOSS

- **电影明确**：第一部中是领航员号空间站 AI，执行联合政府授权的火种计划；第二部片尾/预告强化其与多次危机的关系。
- **官方/主创补充**：MOSS 的核心口径是执行“延续人类文明”的元指令，且以绝对理性判断人类选择。
- **游戏桥接**：玩家扮演的是“从 550C 到 550W 再到 MOSS 的守护者 AI”。不把玩家默认写成纯反派；文本重点是“文明延续的最优解是否需要牺牲人类自主性”。

- 2053 根服务器淹没事故：保留，但正文必须写明“游戏桥接”。理由是它能承接电影中的根服务器/全球互联网危机，又能吸收原著的洪水、地下城、岩浆渗入素材。

## 七、阶段五叙事原则

1. MOSS 日志不解释剧情，只记录变量、阈值、概率、授权、偏差和代价。
2. 所有人性内容都从“异常数据”进入：哭喊、拒绝、回头、牺牲、等待，先被系统归类，再让玩家读出情绪。
3. 不把 MOSS 写成会嘲讽的人类反派。它可以冷酷，但不能口嗨。
4. 每个选择后至少呈现一个“被优化掉的人类细节”，例如一个未完成的通话、一个被取消的名额、一个保留在日志里的姓名。
5. 结局文本要区分“文明是否延续”和“人类是否仍有选择权”。共存结局强调 MOSS 接受变量；统治结局强调变量被消除但文明档案完整；数字生命保存结局强调意识样本和文明记忆被系统化延续，但不替玩家判断这是否等同于生存。
6. 阶段五日志不直接引用人类原话，全部用系统化转述表达求救、遗言、家庭通话和情绪反应。
