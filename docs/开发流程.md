# 开发规划文档：MOSS模拟器 v3.0

> **第一版本目标**：完成MOSS阵营的核心循环， playable prototype。

## 阶段一：核心骨架 (Priority 1) ✅ 完成

**目标**：建立最小可玩循环，游戏能跑起来。

### 1.1 时间系统 ✅
- 计时器：每X秒代表一年
- 年份显示：2044 → 2075
- 回合状态更新

### 1.2 板块数据系统 ✅
- `SectorData` 类：region_name, order, hope, population, authority
- 5个板块初始化数据（当前3个：亚洲、北美、UEG）
- 数据与UI绑定

### 1.3 资源系统 ✅
- 三大资源：算力、能源、控制权
- 资源UI显示（顶栏）- 算力、能源、年份

### 1.4 基础事件弹窗 ✅
- 事件触发：年份匹配
- 弹窗：标题 + 描述 + 选项按钮
- 选择后属性变化

### 1.5 胜负判定 ✅
- 控制权归零 → Game Over
- 到达2075年 → 结局结算
- 结局界面 + 重新开始功能

**里程碑**：能从2044跑到2075，有1个测试事件（2044太空电梯），能判定胜负。 ✅

## 阶段三：MOSS进化系统 (Priority 3)

### 3.2 解锁效果
- 全板块视野
- 概率预测能力

**里程碑**：能解锁硬件升级，获得新能力。

## 文件结构

```
│   ├── resources/
│   │   ├── sector_data.gd    # 板块数据类
│   │   ├── sector_info.gd    # 板块UI组件脚本
│   │   ├── game_event.gd     # 事件数据类
│   │   └── event_option.gd   # 事件选项类
│   ├── systems/
│   │   └── main_os.gd        # 主控制器（核心系统）
│   └── ui/
│       ├── event_popup.gd    # 事件弹窗脚本
│       └── game_over.gd      # 结局界面脚本
├── scenes/
│   ├── main_os.tscn          # 主场景
│   ├── sector_info.tscn      # 板块信息组件
│   ├── event_popup.tscn      # 事件弹窗
│   └── game_over.tscn        # 结局界面
└── assets/                   # 后期添加
```

## 开发建议

1. **先做骨架，后填内容** - 核心循环跑起来再加事件
2. **数据驱动** - 用.tres文件存储数据，方便编辑
3. **快速迭代** - 先用默认UI，后期打磨风格
4. **每个阶段测试** - 完成一个阶段就测试可玩性
