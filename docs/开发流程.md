> **第一版本目标**：完成MOSS阵营的核心循环， playable prototype。

## 阶段一：核心骨架 (Priority 1) ✅ 完成

**目标**：建立最小可玩循环，游戏能跑起来。

### 1.1 时间系统 ✅
- 计时器：每X秒代表一年
- 年份显示：2044 → 2075
- 回合状态更新

### 1.2 板块数据系统 ✅
- `SectorData` 类：region_name, order, hope, population, authority
- 5个板块初始化数据（当前3个：亚洲、北美、UEG）
- 数据与UI绑定

### 1.3 资源系统 ✅
- 三大资源：算力、能源、控制权
- 资源UI显示（顶栏）- 算力、能源、年份

### 1.4 基础事件弹窗 ✅
- 事件触发：年份匹配
- 弹窗：标题 + 描述 + 选项按钮
- 选择后属性变化

### 1.5 胜负判定 ✅
- 控制权归零 → Game Over
- 到达2075年 → 结局结算
- 结局界面 + 重新开始功能

**里程碑**：能从2044跑到2075，有1个测试事件（2044太空电梯），能判定胜负。 ✅

## 阶段二：MOSS指令系统 (Priority 2) ✅ 完成

**目标**：玩家能主动操作。

### 2.1 简化指令（2个）✅
- 算力分配：消耗20算力，提升板块秩序或希望+15，冷却3年
- 系统接管：消耗30算力+20能源，提升控制权+10，冷却5年
- ~~概率预测~~：暂不实现（事件固定触发，无预测意义）

### 2.2 指令UI ✅
- 指令按钮：显示消耗、冷却状态、tooltip提示
- 板块选中：金色边框高亮（StyleBoxFlat，不影响进度条）
- Toggle行为：点击已选中板块取消选中
- 算力分配弹窗：选择提升秩序或希望，实时更新板块名称
- 取消按钮：可关闭弹窗不执行指令
- 算力恢复：每年恢复5点

**里程碑**：玩家能执行2个基础指令，有冷却机制。 ✅

## 阶段三：MOSS进化系统 (Priority 3) ✅ 完成

**目标**：硬件升级解锁新能力。

### 3.1 进化数据类 ✅
- `EvolutionData` 类：定义进化能力属性
- 支持被动能力（自动解锁）和主动指令（购买解锁）

### 3.2 进化能力配置 ✅
- 3个被动能力：冷却缩减、算力上限突破、恢复速度提升
- 3个可购买指令：能源转换、全局接管、危机预测

### 3.3 解锁机制 ✅
- 双重阈值：算力阈值 + 控制权阈值
- 每年自动检查解锁条件
- 购买指令消耗算力

### 3.4 进化UI ✅
- EvolutionPopup：进化详情弹窗（显示已解锁、可购买）
- EvolutionNotice：解锁通知弹窗
- 进化按钮：右上角显示当前等级

**里程碑**：能解锁硬件升级，获得新能力。 ✅

**commits:**
- `540336b` - EvolutionData数据类
- `4e30e50` - 6个进化能力数据文件
- `62b3cad` - 进化状态变量和核心函数
- `5aac619` - 弹窗节点路径修复

**数值状态（待优化）**：
- 初始算力30，恢复10/年，上限100
- 解锁阈值需要系统性重新设计

## 开发建议

1. **先做骨架，后填内容** - 核心循环跑起来再加事件
2. **数据驱动** - 用.tres文件存储数据，方便编辑
3. **快速迭代** - 先用默认UI，后期打磨风格
4. **每个阶段测试** - 完成一个阶段就测试可玩性
