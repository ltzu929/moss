# 阶段四：事件内容 - 细节问题清单

> 进入本阶段前，逐项和AI讨论确定。按 `../../dev/决策流程.md` 的提问模板格式提问。

---

## 数值问题

- [ ] 事件选项的资源消耗/奖励数值范围
- [ ] 不同选项对秩序/希望/人口的影响幅度
- [ ] 事件失败/成功的判定阈值（如果有概率机制）

## UI问题

- [ ] 事件弹窗的视觉层次（标题、描述、选项按钮的样式优先级）
- [ ] 选项按钮的hover/pressed状态反馈
- [ ] 事件图片是否需要，如果需要是什么风格
- [ ] 事件弹窗出现/消失的动画效果

## 内容问题

- [ ] 每个事件的3个选项各自代表什么立场（理性/感性/中立？）
- [ ] MOSS对每个选择的评论语气模板
- [ ] 事件文本的字数限制
- [ ] 事件描述与选项的关联方式（选项是否需要呼应描述中的具体内容）
- [ ] 6个活动事件之间的叙事连贯性

---

## 使用说明

1. 进入阶段四前，先完成所有 `[ ]` 项的讨论
2. 每讨论完一项，在 `[ ]` 中填入 `x` 变成 `[x]`
3. 讨论结论写入对应的领域文档（../../design/数值设计.md / ../../design/UI交互规范.md / ../../design/游戏内容规范.md）
4. 全部完成后开始阶段四的开发工作
