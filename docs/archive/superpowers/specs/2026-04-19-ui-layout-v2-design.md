# MOSS模拟器 - UI布局优化设计 v2

> 日期：2026-04-19
> 状态：设计中

---

## 一、设计背景

当前主界面使用 `HBoxContainer` 水平排列7个板块卡片，总宽度约1554像素，导致大洋洲和南美板块超出屏幕范围，用户无法看到和操作。

---

## 二、布局决策

### 2.1 板块网格布局

**方案：3列网格（GridContainer）**

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 列数 | 3列 | 单屏展示所有板块 |
| 排列顺序 | 行优先（B1） | 亚洲→北美→欧洲→非洲→俄罗斯→大洋洲→南美 |
| 卡片尺寸 | 动态调整，minimum_size 180×300 | 适配不同屏幕，后续可调整 |

排列示意：
```
┌─────┐ ┌─────┐ ┌─────┐
│亚洲 │ │北美 │ │欧洲 │
└─────┘ └─────┘ └─────┘
┌─────┐ ┌─────┐ ┌─────┐
│非洲 │ │俄罗斯│ │大洋洲│
└─────┘ └─────┘ └─────┘
┌─────┐
│南美 │
└─────┘
```

### 2.2 年份进度条

**位置：顶部单独一行**

- 显示 2044→2075 的进度
- 简洁样式：`2044 ━━━━━━━━━━━━━━━━ 2075`

### 2.3 MOSS状态面板

**位置：右侧固定面板**

| 显示内容 | 说明 |
|----------|------|
| 当前等级 | Lv.1 / Lv.2 / Lv.3 |
| 控制权总和 | 百分比显示 |
| 查看详情按钮 | 点击弹出进化详情窗口 |

**简化原则**：面板只显示核心信息，详情通过弹窗查看。

## 三、整体布局结构

```
┌─────────────────────────────────────────────────────────┐
│ 顶部状态栏                                              │
│ MOSS型号 | 算力 | 能源                                  │
├─────────────────────────────────────────────────────────┤
│ 年份进度条（单独一行）                                   │
│ 2044 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 2075         │
├───────────────────────────────────┬─────────────────────┤
│  板块网格区（3列，GridContainer） │  MOSS状态面板        │
│                                   │                     │
│  [亚洲] [北美] [欧洲]             │  Lv.1              │
│  [非洲] [俄罗斯] [大洋洲]         │  控制权: 10%        │
│  [南美]                           │  [查看详情]         │
│                                   │                     │
│  (卡片尺寸动态调整)               │  (固定宽度约150px)  │
├───────────────────────────────────┴─────────────────────┤
│ 底部指令栏                                              │
│ [算力分配] [系统接管] [其他指令...]                      │
└─────────────────────────────────────────────────────────┘
```
