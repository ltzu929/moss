# 游戏设计文档：MOSS模拟器 v3.0

> **版本规划说明**：本文档包含完整设计愿景。标注 `【第一版本】` 的是优先实现内容，标注 `【后续版本】` 的是扩展内容。

---

## 一、游戏定位

**概括**：2044-2075 年间的策略叙事游戏。第一版本只做 MOSS 阵营，玩家扮演守护者 AI，在危机连锁中管理人类文明并承担选择代价。

**资料层级**：
- **电影主线优先**：2044 太空电梯危机、2058 月球坠落危机、2075 木星引力危机是第一版硬锚点。
- **原著补充质感**：地下城生活、地表环境、粮食压力、群体恐慌与长期航行心理可用原著补充。
- **游戏桥接事件**：非电影明确情节的事件必须服务 2044-2075 的节奏，并在内容规范中标注为桥接或备选。

**参考作品**：
- 《冰汽时代》 - 道德选择、资源压力、叙事情感
- 《群星》/《钢铁雄心》 - 派系影响、资源链条
- 《流浪地球》系列电影与原著 - 世界观、MOSS角色、灾难质感

## 三、MOSS阵营设计 `【第一版本】`

### 3.1 核心定位

MOSS 的目标是拯救人类文明，但它更相信可计算、可控制、可牺牲的方案。玩家的主要体验不是“做善事”，而是在高压危机里选择如何分配控制权、人心和资源。

### 3.2 资源系统

| 资源 | 用途 | 来源 |
|------|------|------|
| **算力** | 执行指令、购买进化指令 | 每年恢复、进化能力 |
| **能源** | 事件选项、部分指令消耗 | 每年恢复、事件保留 |
| **控制权** | 胜负与结局指标 | 系统接管、事件选择 |

### 3.3 指令系统

**基础指令**：

| 指令 | 效果 | 消耗 |
|------|------|------|
| **算力分配** | 提升选中板块的秩序或希望 | 算力20 |
| **系统接管** | 提升选中板块控制权 | 算力30 + 能源20 |

**进化解锁指令**：

| 指令 | 效果 |
|------|------|
| **能源转换** | 将能源转换为算力 |
| **全局接管** | 全区域控制权提升 |
| **危机预测** | 显示未来5年内的活动事件 |

### 3.4 MOSS进化

| 阶段 | 硬件 | 解锁方向 | 新能力 |
|------|------|----------|--------|
| 初期 | 550C | 默认 | 基础指令 |
| 中期 | 550W | 算力或控制权达标 | 被动能力、进化指令 |
| 后期 | MOSS | 多个被动能力解锁 | 更高上限与全局能力 |

### 3.5 结局分支

| 结局 | 当前判定 |
|------|----------|
| 失败 | 平均控制权 ≤ 0 |
| 共存 | 2075年结算时平均控制权 ≥ 50 |
| MOSS统治 | 2075年结算时平均控制权 < 50 |

**后续版本扩展**：数字生命结局、觉醒结局、多条件结局评价。

## 四、事件系统 `【第一版本】`

### 4.1 活动编年史事件

固定年份触发，自动从 `data/events/` 读取：

| 年份 | 事件 | 定位 |
|------|------|------|
| 2044 | 太空电梯危机 | 电影锚点 |
| 2053 | 大淹没事故 | 原著灾难质感 + 游戏桥接 |
| 2058 | 月球坠落危机 | 电影锚点 |
| 2065 | AI隔离审查 | MOSS主线桥接 |
| 2070 | 西伯利亚发动机群过载 | 引力加速期桥接 |
| 2075 | 木星引力危机 | 电影锚点 |

### 4.2 备选编年史事件 `【后续版本】`

备选事件不放在 `data/events/` 活动目录，避免第一版自动触发。候选内容记录在 `docs/游戏内容规范.md`。

### 4.3 条件事件 `【后续版本】`

属性阈值触发：
- 希望过低 → 暴动/逃亡
- 控制权过高 → 调查/隔离

### 4.4 阵营事件 `【后续版本】`

- MOSS：渗透暴露、权限审计、数字生命诱导
- UEG：法案争议、派系冲突、MOSS信任危机

## 五、情感呈现 `【第一版本后续阶段】`

### 5.1 MOSS黑话日志

底部滚动显示：
```
[SYSTEM] 变量清除完毕。逻辑闭环。
```

事件选择后显示 MOSS 式冷处理日志，让玩家看到每次“最优解”背后的人类代价。
