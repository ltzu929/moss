# 地区职能、社会压力和政治倾向

地区政治不独立成链，而是作为事件链中的表现层。每个地区固定三项：工程职能、社会压力、政治倾向。

## 亚洲

- 工程职能：人口与工业核心区，承接根服务器、地下城和发动机配套工程。
- 社会压力：人口密度高，地下城资格、医疗、家庭分离和教育压力突出。
- 政治倾向：支持流浪地球计划，但对高权限 AI 接管保持现实主义态度。

用法：

- 适合 2058 根服务器、图恒宇/马兆任务和地下城民生反馈。

## 非洲

- 工程职能：太空电梯和前线工程区。
- 社会压力：工程伤亡、设施袭击、安保漏洞和外来人员压力。
- 政治倾向：对移山工程有强参与感，但对被牺牲为前线区域敏感。

用法：

- 适合 2044 太空电梯余波、安保审查和工程修复新闻。

## 俄罗斯

- 工程职能：西伯利亚发动机群和高压推进前线。
- 社会压力：长期纪律化、低希望、工程伤亡和极端环境。
- 政治倾向：接受强组织和强调度，但对持续牺牲积累怨气。

用法：

- 适合 2070 工程疲劳链和终局前能源压力。

## 北美

- 工程职能：科研、算力储备、数据中心和深空任务支持。
- 社会压力：社会信任脆弱，信息泄露、数字生命争议和审计压力较强。
- 政治倾向：重视技术制衡和透明审查。

用法：

- 适合 AI 审查、数字生命暗流和公共决策模型反馈。

## 南美

- 工程职能：资源、农业保障和后方供给。
- 社会压力：配给、迁移、能源调度和生态损耗。
- 政治倾向：更关注生存资源和地区公平。

用法：

- 适合普通人反馈、资源调配和地下城配给新闻。

## 大洋洲

- 工程职能：孤立后备区、恢复型操作和区域互助节点。
- 社会压力：隔离、运输困难、后备设施承压。
- 政治倾向：倾向自治和区域互助。

用法：

- 适合人类赋能路线、区域互助网络和危机后的恢复新闻。

## 联合政府

- 工程职能：全球决策中枢、授权协议、审查和资源协调。
- 社会压力：各国利益冲突、公众信任、路线争议和政治责任。
- 政治倾向：追求全局稳定，愿意在危机中授权 550/MOSS，但必须控制其边界。

用法：

- 适合协议点解释、2065 审查、结局前最终授权争议。
