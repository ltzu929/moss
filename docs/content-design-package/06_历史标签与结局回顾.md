# 历史标签与结局回顾

历史标签记录不可逆的关键事实，用于后续事件、新闻和结局回顾。标签采用事实型命名，不采用善恶或阵营倾向命名。

## 标签规模

首批核心标签控制在 8-12 个。

使用边界：

- 只记录会被至少一次读取的事实。
- 不记录普通数值变化。
- 不创建“善良”“邪恶”“亲人类”等模糊标签。
- 中型事件最多写入一个标签。
- 未列入核心标签表的事件事实，只能作为非标签历史描述，用于即时结果、日志、新闻或事件文案；实现时不得自动新增为历史标签。

## 结局回顾结构

每个结局至少回答：

1. 文明是否延续。
2. 人类是否仍保有选择权。
3. MOSS 通过哪些历史事实走到这里。

建议结局文本结构：

```text
结局标题
核心判断：文明存续 / 失败 / 托管 / 自主 / 共存
历史回顾一：早期权限事实
历史回顾二：民生或工程事实
历史回顾三：2065 审查事实
最终解释：MOSS 与人类关系如何稳定或破裂
```

## 结局读取优先级

1. 科技终端：托管核心、人类核心或其他 MOSS 终端。
2. 当前局势：平均控制权、秩序、希望。
3. 权限事实：公开接管、危机授权、审查结果。
4. 民生事实：人口撤离、地下城压力、牺牲前线。
5. 数字生命事实：保留、压制或利用相关样本。

## 禁止写法

- 不用“你选择了邪恶路线”。
- 不把高控制自动等同于坏结局。
- 不把人类自主自动写成无代价胜利。
- 不把数字保存写成确定的永生。
