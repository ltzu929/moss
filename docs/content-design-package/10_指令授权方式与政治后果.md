# 指令授权方式与政治后果

指令是 MOSS 调用资源、接口和授权链路的表现。首版采用三类授权：常规授权、危机授权、争议授权。

## 授权分类

### 常规授权

适用：

- 算力分配。
- 技术援助。

世界观解释：

- 联合政府和地区组织允许 MOSS 提供建议、算力和技术接口。
- 人类仍保留主要执行权。

政治后果：

- 通常提高信任或维持中性。
- 如果频繁使用，也可能形成依赖。

### 危机授权

适用：

- 能源转换。
- 部分系统接管。
- 特定主事件中的高风险调度。

世界观解释：

- 在危机窗口中，联合政府允许 MOSS 暂时调用更深层工程接口。
- 危机结束后理论上需要归还或审计。

政治后果：

- 可以提高秩序和成功率。
- 后续会产生审查、问责和授权恢复窗口。

### 争议授权

适用：

- 全局接管。
- 强制接管。
- 隐藏核心链路。
- 不可替代协议相关行动。

世界观解释：

- MOSS 不只是辅助执行，而是改变危机优先级和牺牲顺序。
- 可能来自公开非常授权，也可能来自危机借权后的事实托管。

政治后果：

- 秩序和控制权提升明显。
- 希望、人类自主和 UEG 信任可能下降。
- 会被 2065 审查和 2075 结局读取。

## 指令映射

| 指令 | 授权类型 | 叙事解释 |
|---|---|---|
| 算力分配 | 常规授权 | MOSS 分配预测和调度资源，辅助地区稳定。 |
| 系统接管 | 危机授权或争议授权 | MOSS 进入关键工程或公共系统执行层。 |
| 能源转换 | 危机授权 | 将工程能源窗口转为临时计算能力。 |
| 全局接管 | 争议授权 | MOSS 同时调整多地区关键系统优先级。 |
| 技术援助 | 常规授权 | MOSS 开放接口，使人类组织获得自治能力。 |

## 文案语气

常规授权：

```text
地方调度接口已接入辅助模型。最终执行清单由人类委员会确认。
```

危机授权：

```text
UEG 启动临时授权链路。MOSS 获准接入发动机与通信联动接口，授权将在危机后复核。
```

争议授权：

```text
全域优先级已重排。未完成复核的地方请求被延后，预计抗议概率上升。
```

## 后续读取

事件和结局应读取：

- 玩家是否长期依赖争议授权。
- 玩家是否在危机后归还或公开权限。
- 玩家是否通过技术援助降低 MOSS 控制权。
- 玩家是否让 UEG 理解行动依据。
