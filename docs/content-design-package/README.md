# 游戏内容设计包

本目录记录《MOSS 模拟器》世界观与游戏内容设计讨论形成的阶段性共识，服务后续事件、事件链、新闻、科技说明、指令解释、地区差异和结局回顾设计。

## 使用边界

- 本目录是内容设计包，不是实现计划。
- 不替代 `docs/worldbuilding/` 和 `docs/lore/` 的来源规则。
- 不把解析视频推断写成原作事实。
- 游戏原创内容必须标注为游戏桥接，并说明服务的玩法或叙事问题。
- 后续实现时，应先从本包提取事件职责、历史标签和文本规则，再决定 `.tres`、代码和测试改动。

## 总体规模

- 保留现有 6 个主事件。
- 后续新增 12-18 个中型事件，当前建议 15-17 个。
- 建立 4 条跨年份事件链。
- 增加 30-50 条新闻、日志或普通人反馈。
- 为科技、指令和地区补充叙事解释。
- 让结局能够回顾玩家早期重要选择。
