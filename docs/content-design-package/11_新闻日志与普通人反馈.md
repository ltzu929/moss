# 新闻日志与普通人反馈

新闻和日志优先表现数值背后的人类后果。目标是让秩序、希望、控制权和能源变化不只是抽象数值。

## 叙事视角

采用多源拼贴：

- UEG 公报。
- 地方新闻。
- 工程记录。
- MOSS 系统日志。
- 民间通信。
- 审计摘要。

## 文本职责

| 数值或系统 | 普通人后果 |
|---|---|
| 秩序上升 | 治安恢复、工程排班稳定、撤离队列缩短、配给点重开。 |
| 秩序下降 | 抗议、抢修延误、交通封锁、地下城冲突。 |
| 希望上升 | 家庭通信恢复、志愿组织扩张、学校复课、地方互助。 |
| 希望下降 | 抽签绝望、谣言、失踪名单、心理崩溃、逃离工作岗位。 |
| 控制权上升 | MOSS 接入更多系统、地方决策被重排、自动化替代人工判断。 |
| 控制权下降 | 地方自治增强、响应变慢、人类组织承担更多错误。 |
| 能源下降 | 停机窗口、配给收紧、照明降低、工程优先级重排。 |

## 样本文案方向

UEG 公报：

```text
UEG 宣布临时授权链路进入复核期。各地区须提交 MOSS 调度接口使用记录。
```

地方新闻：

```text
南美三处配给站恢复开放。居民称队列变短了，但燃料券仍按家庭编号发放。
```

工程记录：

```text
西伯利亚三号阵列完成降载。维修队报告热屏蔽材料库存低于安全线。
```

MOSS 日志：

```text
[SYSTEM] 授权链路恢复。未接通的家庭通信已转入归档。
```

民间通信：

```text
“抽签结果出来了。父亲中了，母亲没有。系统建议我们明天前完成家庭拆分登记。”
```

## 新闻分配建议

| 主题 | 数量建议 |
|---|---:|
| 地下城资格、配给、迁移 | 8-12 |
| 工程疲劳、发动机、根服务器 | 6-10 |
| 数字生命暗流、泄露、审查 | 5-8 |
| UEG 授权、公报、政治争议 | 5-8 |
| MOSS 系统日志 | 6-10 |
| 地区差异反馈 | 6-10 |

## 禁止写法

- 不用新闻直接替玩家评价选择对错。
- 不把普通人写成只会恐慌或只会服从。
- 不让所有文本都像 MOSS 日志。
- 不把来源不明的解析推断写成新闻事实。
