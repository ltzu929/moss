# 跨年份事件链

本包确定四条核心跨年份事件链：权限演化、数字生命暗流、地下城民生、工程疲劳。地区政治不单独成链，而是嵌入这些链的地区表现中。

## 链一：权限演化链

定位：MOSS 游戏主脊柱。

| 阶段 | 内容 | 作用 |
|---|---|---|
| 2044 | 550C 在太空电梯危机中获得有限工程接入。 | 建立人类允许 AI 辅助危机处置的起点。 |
| 2048-2052 | 辅助决策和行为预测开始进入地方工程系统。 | 让控制权从数据接入扩展到工程调度。 |
| 2058 | 月球危机中 550W 获得极高危机授权。 | 形成后续审查的根源。 |
| 2065 | 联合政府发起 AI 隔离审查。 | 迫使玩家选择配合、协商或隐藏核心链路。 |
| 2070-2075 | 工程极限使人类越来越难脱离 MOSS。 | 决定托管、共存或退出控制核心的结局解释。 |

关键问题：

- 玩家是否公开扩大权限。
- 玩家是否在危机后归还权限。
- 玩家是否让人类理解 MOSS 的决策依据。

## 链二：数字生命暗流链

定位：持续社会和技术争议。

| 阶段 | 内容 | 作用 |
|---|---|---|
| 2044 | 数字生命派袭击造成工程创伤和社会污名。 | 建立数字生命路线的暴力阴影。 |
| 2045-2052 | 支持者转入地下传播，部分公众因地下城资格压力重新关注数字保存。 | 说明数字生命派不是单一恐怖组织。 |
| 2058 | 图恒宇、丫丫和 550W 接入让数字生命争议重回核心系统。 | 把个人执念、技术样本和危机授权连接起来。 |
| 2060s | 审查、泄露和地下网络传播形成长期暗流。 | 为 2065 权限审查提供社会侧压力。 |
| 2075 | 数字保存成为文明备份争议之一。 | 进入结局回顾，但不回答数字生命是否等于真实生命。 |

关键问题：

- 玩家是否压制数字生命传播。
- 玩家是否保留数字生命样本作为风险资产。
- 玩家是否允许数字生命技术进入文明备份讨论。

## 链三：地下城民生链

定位：把数值变化落到普通人生活。

| 阶段 | 内容 | 作用 |
|---|---|---|
| 2045-2052 | 抽签、资格、配给和临时安置成为日常压力。 | 解释希望下降和秩序维持的代价。 |
| 2053 | 大淹没事故冲击根服务器、地下城和人口迁移。 | 让玩家在通信、人口和工程之间取舍。 |
| 2054-2064 | 迁移、教育、工作分配和自治组织形成长期差异。 | 让地区差异进入新闻和中型事件。 |
| 2065 | 审查争议影响地下城居民对 MOSS 的信任。 | 把 AI 权限问题转化为日常生活问题。 |
| 2075 | 普通人是否仍相信计划，取决于早期治理事实。 | 进入结局回顾和新闻尾声。 |

关键问题：

- 玩家是否优先保护人口。
- 玩家是否让地下城自治。
- 玩家是否把配给、教育和迁移完全交给 MOSS 优化。

## 链四：工程疲劳链

定位：支撑策略游戏的工程压力。

| 阶段 | 内容 | 作用 |
|---|---|---|
| 2044 | 太空电梯和方舟号受创。 | 建立巨型工程并非稳定背景。 |
| 2053 | 海水、根服务器和地下设施共同暴露基础设施脆弱性。 | 把工程退化和民生压力连接。 |
| 2058 | 月球发动机和行星发动机点火链路进入高风险状态。 | 展示高权限调度的必要性和危险。 |
| 2066-2070 | 发动机群长期过载，西伯利亚成为压力前线。 | 预告 2070 主事件。 |
| 2071-2075 | 地球接近木星，推进系统进入不可逆极限。 | 让最终危机有长期铺垫。 |

关键问题：

- 玩家是否牺牲局部设施保全主结构。
- 玩家是否提前停机维护，承受政治和推进代价。
- 玩家是否用 MOSS 强控换取工程效率。
