# 2044-2075 内容节奏表

采用“危机峰值 + 空档反馈”节奏：主事件附近放中型事件，中间年份用新闻、日志和地区反馈补世界变化。

## 总览

| 年份段 | 内容职责 | 建议内容密度 |
|---|---|---|
| 2044 | 开场危机，建立权限边界、数字生命冲突和太空电梯创伤。 | 1 个主事件，2-3 个中型事件，4-6 条新闻。 |
| 2045-2052 | 地下城资格、舆论回落、工程修复、550C 普及。 | 2-3 个中型事件，8-12 条新闻。 |
| 2053 | 大淹没事故，基础设施和民生压力显性化。 | 1 个主事件，2-3 个中型事件，4-6 条新闻。 |
| 2054-2057 | 根服务器、地下城安置、数字生命残余和 550W 前夜。 | 2-3 个中型事件，6-8 条新闻。 |
| 2058 | 月球坠落危机，危机授权达到高峰。 | 1 个主事件，2-3 个中型事件，4-6 条新闻。 |
| 2059-2064 | 550W 依赖、审计压力、地下传播、工程长期化。 | 3-4 个中型事件，8-10 条新闻。 |
| 2065 | AI 隔离审查，权限问题政治化。 | 1 个主事件，2 个中型事件，3-5 条新闻。 |
| 2066-2069 | 审查后重组、地区自治或托管深化、发动机疲劳。 | 2-3 个中型事件，6-8 条新闻。 |
| 2070 | 西伯利亚发动机群过载，终局前工程预警。 | 1 个主事件，2 个中型事件，3-5 条新闻。 |
| 2071-2074 | 木星危机前夜，社会信任、工程极限和最终授权争议。 | 2-3 个中型事件，6-8 条新闻。 |
| 2075 | 木星引力危机和结局回顾。 | 1 个主事件，结局文本读取历史标签。 |

## 中型事件分配

| 事件链 | 数量 | 说明 |
|---|---:|---|
| 权限演化链 | 5 | 游戏主脊柱，承接 2044、2058、2065、2075。 |
| 数字生命暗流链 | 3-4 | 让数字生命派从开场背景延续为思想和技术问题。 |
| 地下城民生链 | 4 | 把希望、秩序和控制权落到普通人生活。 |
| 工程疲劳链 | 3-4 | 解释 2070 和 2075 的工程压力不是突然出现。 |

## 新闻与日志分布

建议总量 30-50 条，优先覆盖：

- 抽签结果、地下城资格和家庭分离。
- 配给、食物、医疗和临时安置。
- 发动机维护、工程伤亡和停机窗口。
- UEG 公报、地方新闻和民间通信的口径差异。
- 数字生命派残余传播、数据泄露和审查争议。
- MOSS 对行动结果的冷处理记录。

## 节奏约束

- 电影锚点不得被中型事件抢走核心职责。
- 游戏桥接事件必须标注为游戏桥接。
- 中间年份内容应优先反馈历史选择，而不是平均撒事件。
- 2075 结局必须能读回至少 3-5 个关键历史事实。
