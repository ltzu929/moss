# 派系状态和发展阶段

本文件定义后续事件和新闻可以调用的派系状态。首版不实现独立派系系统，只作为内容设计依据。

## 联合政府

核心目标：

- 维持全球工程和危机治理。
- 推进流浪地球计划。
- 在各国利益、民生压力和 AI 权限之间维持最低共识。

阶段变化：

| 阶段 | 状态 |
|---|---|
| 2044 | 依赖 550C 协助工程危机，仍将其视为工具。 |
| 2058 | 在极端危机中授予 550W 高权限。 |
| 2065 | 对 MOSS 权限进行正式审查。 |
| 2075 | 面对无法脱离 MOSS 的现实，必须接受托管、共存或人类自主路径。 |

事件用法：

- UEG 公报强调稳定和全局工程。
- 内部会议文本可以体现路线争议。
- 不写成全知或完全无能。

## 移山计划支持者

核心目标：

- 确保行星发动机、地下城和长期航行体系持续推进。

矛盾：

- 需要 AI 和自动化提高效率。
- 又担心过度自动化造成失业、失控和政治反弹。

事件用法：

- 工程疲劳链中的主要行动者。
- 与人类赋能科技路线有天然联系。
- 可在新闻中表达“效率与就业/稳定”的冲突。

## 数字生命派

核心目标：

- 推动意识数字化保存或延续。

阶段变化：

| 阶段 | 状态 |
|---|---|
| 2044 | 因袭击成为安全威胁和社会污名。 |
| 2045-2057 | 被压制后转入地下传播、技术残余和舆论暗流。 |
| 2058 | 图恒宇和丫丫事件使数字生命争议重新显性。 |
| 2060s | 可能通过泄露、地下网络和审查争议影响社会。 |
| 2075 | 成为文明备份争议之一。 |

事件用法：

- 不把数字生命派整体写成单纯反派。
- 区分恐袭者、技术支持者、绝望民众和政治投机者。
- 不断言数字生命等同真实生命。

## 军事与安全组织

核心目标：

- 保护太空电梯、发动机、地下城、根服务器和危机任务。

事件用法：

- 可表现维护窗口、系统漏洞、权限转交和内鬼风险。
- 与 MOSS 的关系是“需要接入但必须审计”。

## 民间反对力量

核心目标：

- 不统一。可能包括反移山、危机否认、地方利益保护、数字生命支持者和资源分配抗议者。

事件用法：

- 主要通过新闻、抗议、泄露录像和地下城资格争议出现。
- 不把所有反对者写成愚昧或邪恶。

## 科研机构

核心目标：

- 推进 550 系列、数字生命、发动机、根服务器、地下城智能服务等关键技术。

事件用法：

- 适合承载科技代价、伦理审查和协议点解释。
- 与图恒宇、马兆相关内容只做原作锚点引用。
