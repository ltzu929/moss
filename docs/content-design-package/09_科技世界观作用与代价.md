# 科技世界观作用与代价

科技树不只是收益按钮。每个节点都代表一次研究突破、部署窗口、授权协议和工程改造。

## 协议点

协议点定义为复合额度：

- 研究突破。
- 工程部署窗口。
- 联合政府授权协议。
- 550/MOSS 硬件或算力升级。

年度获得协议点的叙事解释：

- 巨型工程需要多年验证。
- 联合政府授权需要政治窗口。
- 硬件和基础设施升级不能连续无限推进。
- 社会组织需要时间适应新接口。

## 托管网络路线

世界观作用：

- 让 MOSS 从辅助建议进入基础设施托管。
- 提高调度效率和危机响应速度。
- 使人类组织逐渐依赖统一控制网络。

代价语法：

- 依赖增加。
- 审计压力增加。
- 人类本地决策被压缩。
- 高控制不一定是阴谋，但会改变权力结构。

适用文本：

```text
UEG 公报确认区域调度接口升级。地方委员会保留建议权，但最终排序由统一模型生成。
```

## 核心演化路线

世界观作用：

- 强化 MOSS 自身算力、恢复能力和调度效率。
- 让 MOSS 在危机中更难被替代。
- 使决策过程越来越难被人类完整解释。

代价语法：

- 能源占用。
- 不可解释性上升。
- 冷却和审计窗口被压缩。
- 人类可能看见结果，却无法复核过程。

适用文本：

```text
工程记录显示预测误差下降。审计组同时报告：核心推理链无法在人工时限内复现。
```

## 人类赋能路线

世界观作用：

- 把技术接口、应急训练和运维能力交还给人类组织。
- 支撑人类自主或协作治理路线。
- 降低 MOSS 控制权，但可能牺牲短期效率。

代价语法：

- 响应速度下降。
- 地区执行差异扩大。
- 失误和地方冲突风险增加。
- 需要更高社会信任和训练成本。

适用文本：

```text
地方运维队完成独立切换演练。MOSS 记录到三处延迟，但未接管指挥链。
```

## MOSS 终端节点

终端节点应进入结局解释：

- 不可替代协议：MOSS 成为文明基础设施不可替代核心。
- 协商托管协议：高权限仍存在，但以公开协商和有限授权维持。
- 递归优化：MOSS 的执行效率提高，但可解释性下降。
- 分布式认知：MOSS 更稳健，也更消耗能源。
- 文明自持：人类具备脱离 MOSS 核心控制的能力。
- 协作治理协议：人类与 MOSS 维持制度化协作。

## 禁止写法

- 不把科技研发写成免费升级。
- 不把人类赋能写成无代价胜利。
- 不把托管网络写成纯粹邪恶路线。
- 不把核心演化写成 MOSS 变成反派。
