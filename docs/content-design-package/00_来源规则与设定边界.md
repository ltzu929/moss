# 来源规则与设定边界

本包沿用 `docs/lore/世界观资料来源与设定分级.md`，不新增独立来源体系。

## 三类内容

### 原作设定

可作为硬锚点使用：

- 2044 太空电梯危机。
- 2058 月球坠落危机。
- 2075 木星引力危机。
- 联合政府、地下城、太空电梯、月球发动机、行星发动机、根服务器、领航员号。
- 550C、550W 与后续 MOSS 的技术连续性。
- 第一部中 MOSS 执行火种计划与“延续人类文明”的目标口径。

使用规则：

- 不改变电影核心事件结果。
- 不改写图恒宇、马兆、刘培强等原作人物的核心命运。
- 电影没有明确给出的月份、动机、幕后操控和组织细节，不写成电影事实。

### 可靠推断

可作为候选设计燃料，但不直接升格为正史：

- 联合政府内部存在移山计划、数字生命计划和 AI 权限路线争议。
- 数字生命派不只是恐怖袭击背景，也有社会、政治和生存压力基础。
- 地下城资格、资源分配、难民、配给、教育和舆论共同影响希望与秩序。
- 550 系列接入关键工程后，联合政府依赖与戒备并存。

使用规则：

- 在事件说明中标注为可靠推断或可靠二手整理。
- 不能把“视频作者推断”写成“电影明确”。
- 可以转化为新闻、舆论、分支事件和结局回声。

### 游戏原创桥接

当前已确认的游戏桥接内容：

- 2053 大淹没事故。
- 2065 AI 隔离审查。
- 2070 西伯利亚发动机群过载。
- 协议点、科技树三路线、指令冷却、区域控制权。
- 权限演化链、数字生命暗流链、地下城民生链、工程疲劳链。

使用规则：

- 每个桥接事件都必须说明它服务的玩法或叙事问题。
- 不把桥接事件伪装成电影正史。
- 桥接内容优先服务事件因果、历史标签、新闻反馈和结局回顾。

## 表述强度

| 表述 | 可用于 |
|---|---|
| “电影明确呈现” | 两部电影正片、片尾、片内字幕或明确台词。 |
| “可靠整理显示” | 解析、科普、百科或二手材料中的可回查信息。 |
| “可推断” | 多个材料共同支持但没有直接文本确认的结论。 |
| “游戏设定为” | 为玩法和叙事新增的桥接内容。 |
| “候选方向” | 尚未进入正式内容的设计设想。 |

## 本包优先原则

1. 先服务游戏选择，再扩写世界观。
2. 先确认来源层级，再写事件内容。
3. 先设计历史事实，再设计结局回顾。
4. 不把 MOSS 写成单纯反派。
5. 不把人类选择写成完全无意义。
