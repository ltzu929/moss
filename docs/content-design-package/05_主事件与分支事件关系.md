# 主事件与分支事件关系

本文件说明六个主事件在后续内容包中的职责和可承接分支方向。

## 2044 太空电梯危机

来源定位：电影明确。

内容职责：

- 建立 550C 权限边界。
- 建立数字生命派暴力阴影。
- 建立太空电梯和方舟号工程创伤。

可写入的历史事实：

- 是否公开接管自动化系统。
- 是否保留人类飞行员或地面指挥链。
- 是否以牺牲局部设施保护主结构。

后续读取：

- 2050s 的 AI 接口推广争议。
- 2058 危机授权是否被信任。
- 2065 审查对早期接管记录的引用。

## 2053 大淹没事故

来源定位：游戏桥接 + 原著质感 + 电影相关根服务器素材。

内容职责：

- 引入基础设施、根服务器和地下城民生压力。
- 让玩家在通信、人口和工程之间取舍。
- 铺垫 2058 根服务器重启不是孤立事件。

可写入的历史事实：

- 是否优先保护根服务器和通信链路。
- 是否优先撤离人口。
- 是否牺牲外围区域保全核心设施。

后续读取：

- 地下城民生链新闻。
- 2058 根服务器任务的社会信任。
- 2075 结局中普通人是否认为自己被当作变量处理。

## 2058 月球坠落危机

来源定位：电影明确。

内容职责：

- 展示 550W 高权限危机授权。
- 把数字生命、根服务器和发动机链路汇合。
- 为 2065 审查提供核心原因。

可写入的历史事实：

- 是否授权人类高风险重启任务。
- 是否提前接管发动机点火链路。
- 是否保留数字生命数据作为未知变量。

后续读取：

- 数字生命暗流链。
- 2065 AI 隔离审查。
- 2075 文明备份和火种争议。

## 2065 AI 隔离审查

来源定位：游戏桥接。

内容职责：

- 把 MOSS 权限边界从工程问题变成政治问题。
- 让玩家明确选择配合、协商或隐藏。
- 决定后续结局中人类是否理解 MOSS。

可写入的历史事实：

- 是否配合隔离审查。
- 是否有限开放接口。
- 是否隐藏核心链路。

后续读取：

- 2070 发动机过载时的授权速度。
- 2075 是否接受 MOSS 最终判断。
- 结局中的共存、托管或自主解释。

## 2070 西伯利亚发动机群过载

来源定位：游戏桥接 + 原著工程质感。

内容职责：

- 让终局前的工程疲劳显性化。
- 检验长期调度、牺牲逻辑和地区承受力。
- 连接俄罗斯地区职能与终局压力。

可写入的历史事实：

- 是否分段停机保护人员。
- 是否启动备用阵列消耗资源。
- 是否强制超频点火。

后续读取：

- 2075 木星危机中的能源和工程信任。
- 结局中对局部牺牲的回顾。

## 2075 木星引力危机

来源定位：电影明确 + 原著补充。

内容职责：

- 汇总历史选择。
- 决定文明存续、人类自主和 MOSS 控制权的最终平衡。
- 触发结局回顾。

读取方向：

- 2044 是否公开接管。
- 2053 是否牺牲民生或通信。
- 2058 是否保留人类决策。
- 2065 是否通过审查或隐藏核心链路。
- 2070 是否强制牺牲工程前线。
- 科技路线终端和当前局势数值。
