# 科技树设计

本文档维护当前科技树的产品规则、路线职责和节点效果。运行时接口见 `../dev/技术架构.md`，界面规则见 `UI交互规范.md`，关键数值见 `数值设计.md`。

## 核心规则

- 科技树包含托管网络、核心演化和人类赋能三条路线。
- 三条路线只负责界面分页，不限制跨路线混合激活。
- 开局拥有 1 点协议点；2048 至 2072 每四年获得 1 点，整局共 8 点。
- 每个节点消耗 1 点，本局不可撤销或退款。
- 激活 2 个节点进入 550W，激活 6 个节点进入 MOSS。
- 每条路线的两个 MOSS 终端属于同一互斥组；激活其中一个后，另一个永久锁定。
- 新增节点暂不改变事件内容；现有“应急组织训练”事件减损保持不变。

## 托管网络

| 阶段 | 节点 | 前置 | 效果与代价 |
|------|------|------|------------|
| 550C | 辅助决策接口 | 无 | 算力分配开放综合调度：秩序 +10、希望 +10、控制权 +2 |
| 550C | 行为预测模型 | 无 | 系统接管基础冷却由 5 年降为 4 年 |
| 550W | 基础设施托管 | 辅助决策接口 | 系统接管降至 25 算力、15 能源；控制权 +15、希望 -5 |
| 550W | 全域协调网络 | 辅助决策接口 | 解锁全局接管 |
| 550W | 权限审计链 | 行为预测模型 | 系统接管与全局接管能源消耗各降低 5 |
| MOSS | 不可替代协议 | 基础设施托管、全域协调网络 | 全局接管：全区域秩序 +5、控制权 +8、希望 -5；可解锁 MOSS 托管结局 |
| MOSS | 协商托管协议 | 全域协调网络、权限审计链 | 系统接管控制权 +12 且不损失希望；全局接管秩序 +3、控制权 +6；不解锁托管结局 |

## 人类赋能

| 阶段 | 节点 | 前置 | 效果与代价 |
|------|------|------|------------|
| 550C | 开放技术接口 | 无 | 解锁技术援助：秩序 +10、希望 +10、控制权 -3 |
| 550C | 公共决策模型 | 无 | 单项算力分配主属性 +15、另一属性 +5、控制权 -1；不与综合调度叠加 |
| 550W | 自治运维网络 | 开放技术接口 | 低于 50 的区域秩序和希望每年各恢复 1 |
| 550W | 应急组织训练 | 开放技术接口 | 事件造成的负秩序、负希望影响减轻 25% |
| 550W | 区域互助网络 | 公共决策模型 | 技术援助改为 15 算力、5 能源；秩序 +12、希望 +12、控制权 -4 |
| MOSS | 文明自持 | 自治运维网络、应急组织训练 | 自治恢复提高至每年 +2、上限 60；可解锁人类自主结局与控制权归零存续 |
| MOSS | 协作治理协议 | 自治运维网络、区域互助网络 | 技术援助改为 10 算力、5 能源、冷却 2 年；秩序 +15、希望 +15、控制权 -5；不解锁自主结局 |

## 覆盖优先级

- 所有派生数值都从基础值重新计算，避免重复叠加。
- 协商托管协议覆盖基础设施托管的接管控制权与希望值。
- 协作治理协议覆盖区域互助网络的技术援助数值。
- 其他成本、恢复、上限和冷却修正按标签叠加。

## 结局接口

- 仍只有失败、共存协议、MOSS 托管和人类自主四类结局。
- 只有不可替代协议提供 `managed_core`。
- 只有文明自持提供 `human_core`。
- 三个替代终端会显示在结局科技摘要中，但不新增或替代旧结局条件。
