# 阶段六：整合测试 - 细节问题清单

> 进入本阶段前，逐项和AI讨论确定。按 `决策流程.md` 的提问模板格式提问。

---

## 数值问题

- [ ] 完整流程的时间节奏（2044-2075的实际游玩时长）
- [ ] 整体资源平衡验证（算力/能源/控制权是否够用）
- [ ] 进化解锁时机验证（是否太早/太晚）
- [ ] 胜负边界测试（控制权归零是否过于容易/困难）

## UI问题

- [ ] 完整流程的UI连贯性检查
- [ ] 各弹窗之间的切换是否流畅
- [ ] 信息展示是否足够（玩家是否经常困惑）
- [ ] 错误提示是否清晰

## 内容问题

- [ ] 4个事件的叙事是否连贯
- [ ] MOSS日志是否形成完整故事线
- [ ] 结局是否满足玩家期待
- [ ] 整体体验的情感弧线是否合理

## 使用说明

1. 进入阶段六前，先完成所有 `[ ]` 项的讨论
2. 每讨论完一项，在 `[ ]` 中填入 `x` 变成 `[x]`
3. 讨论结论写入对应的领域文档（数值设计.md / UI交互规范.md / 游戏内容规范.md）
4. 全部完成后开始阶段六的测试工作
5. 测试中发现的新问题，按决策流程补充讨论
