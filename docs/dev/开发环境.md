# 开发环境

本文档维护 Godot、GDScript、Godot AI MCP 和编辑器诊断的当前要求。测试方式见 `测试指南.md`。

## Godot

- 项目配置版本：Godot 4.x。
- 当前 `project.godot` 功能标记：Godot 4.6、Forward Plus。
- 设计分辨率：1920×1080。
- 主场景：`scenes/main_os.tscn`。

使用其他 Godot 4.x 版本前，需要确认场景格式、GDScript 语法和插件兼容性。

## Godot AI MCP

项目包含 `addons/godot_ai/`，并在 `project.godot` 中启用插件。它可以让支持 MCP 的客户端检查场景、创建节点、修改属性、运行项目和搜索文件。

使用条件：

- 使用 Godot 打开当前项目。
- 在 **项目设置 > 插件** 中确认 Godot AI 已启用。
- 在 Godot AI 面板中为当前 MCP 客户端完成配置。
- 按插件要求安装 `uv`，用于运行 Python MCP 服务。

具体插件说明见 `addons/godot_ai/README.md`。

## GDScript LSP

Godot 编辑器打开项目后会提供 GDScript Language Server。编辑器完成导入和索引后，诊断、跳转和引用查找才可靠。

不同客户端的连接配置可能不同，因此本仓库不维护用户级编辑器配置路径。遇到 LSP 问题时优先检查：

1. Godot 是否已打开当前项目。
2. 项目是否完成资源导入和脚本解析。
3. 客户端是否连接到当前 Godot 实例。
4. Godot 输出面板是否存在脚本解析错误。

## 修改场景

节点结构和复杂资源引用优先通过 Godot 编辑器或 Godot MCP 修改。手动编辑 `.tscn` 后必须重新加载场景，并运行与该场景相关的测试。

## 提交前检查

- Godot 没有新增脚本解析错误。
- 修改的场景可以加载。
- 对应自动化测试退出码为 0。
- `.godot/` 导入缓存和用户级编辑器配置没有进入提交。
