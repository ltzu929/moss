# 决策流程

本文档只维护跨领域决策流程和记录方式。具体领域标准见 `../design/数值设计.md`、`../design/UI交互规范.md`、`../design/游戏内容规范.md`。

> 遇到细节问题时，按此流程和AI讨论并记录决策。

---

## 流程步骤

```
1. 打开对应的 phase-checklist 清单（如果处于某开发阶段）
2. 找到需要讨论的问题
3. 按下方「AI提问模板」格式向AI提问
4. 用对应领域的「判断标准」评估AI给的方案
5. 选择方案，按「决策记录格式」写入领域文档
6. 在 phase-checklist 中标记已完成 [x]
7. 继续开发
```

---

## AI提问模板

每次问AI细节问题时，复制此模板填入你的问题：

```markdown
## 问题
[描述你要确定的细节问题]

## 领域
[数值 / UI / 内容]

## 约束条件
[已确定的相关内容，比如"算力上限已定为100"]

## 请AI提供
1. 2-3个方案选项
2. 每个方案的优缺点
3. 你的推荐及理由
4. 用我（不懂这个领域）能理解的语言解释
```

---

## 决策记录格式

讨论完之后，把结论写入对应的领域文档（数值设计.md / UI交互规范.md / 游戏内容规范.md）：

```markdown
### [问题名称]

**决策日期**：YYYY-MM-DD

**最终方案**：[选定的方案]

**选择理由**：[为什么选这个]

**相关约束**：[受哪些已确定内容影响]
```

## 使用示例

### 问题示例

```markdown
## 问题
事件弹窗的选项按钮应该用什么样式？

## 领域
UI

## 约束条件
- 主界面已确定用深色科技风
- 标题用金色强调

## 请AI提供
1. 2-3个方案选项
2. 每个方案的优缺点
3. 你的推荐及理由
4. 用我（不懂这个领域）能理解的语言解释
```

### 记录示例

写入 `UI交互规范.md`：

```markdown
### 事件选项按钮样式

**决策日期**：2024-04-23

**最终方案**：选项按钮用半透明深色背景 + 白色文字 + 金色边框hover效果

**选择理由**：与主界面深色科技风统一，hover时金色边框提供清晰反馈

**相关约束**：主界面深色科技风、标题金色强调
```

## Agent Team 使用说明

Agent Team 是决策辅助工具，只在**讨论阶段**使用。

### Agent 角色

| Agent角色 | 负责领域 | 主要任务 |
|-----------|----------|----------|
| **数值策划** | 数值系统 | 分析数值方案、检查边界情况、评估兼容性 |
| **UI设计师** | UI交互 | 给出样式方案、网页mockup展示（不要截图） |
| **世界观检查员** | 内容一致性 | 检查文本是否符合世界观设定、不负责创作 |

### 使用场景

| 阶段 | 是否使用 | 说明 |
|------|----------|------|
| 讨论方案 | ✅ 使用 | 启动多个专业Agent并行分析 |
| 确定方案 | ❌ 不用 | 你选择后，直接记录结论 |
| 实现代码 | ❌ 不用 | 方案已确定，直接写代码 |

### Agent 输出要求

| 领域 | 输出要求 |
|------|----------|
| 数值 | 3个方案 + 推荐理由（文字即可） |
| UI | 3个方案 + **网页mockup直观展示**（不要截图，不要纯文字） |
| 世界观检查 | 对照世界观文档，列出文本与设定的一致性/不一致性 |

### 改进记录

- UI方案必须用网页展示，不要截图
- 内容Agent改为"世界观检查员"，只负责检查一致性，不负责创作
- Agent Team 只用于讨论，不用于执行
