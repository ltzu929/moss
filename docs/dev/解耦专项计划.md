## 后续架构调整边界

- MainOS 保留月度流程、根模态、资源写回和跨系统编排；不因文件行数继续拆分。
- UI 只消费快照并报告操作，领域服务不反向访问 UI；共享 `.tres` 保持模板只读。
- 预览与真实结算使用同一计算依据；月度顺序、局势资源分配顺序、固定种子与恢复原子性属于行为契约。
- 纯重构不夹带玩法、文案、数值、存档格式或诊断协议变化；需要改变这些行为时单独说明任务范围。
- 不默认新增全局 EventBus、巨型 GameState、依赖注入框架或 Autoload 业务系统。
- 本专项不授权额外 MainOS 拆分；需要继续调整时明确具体问题、目标职责与验证范围。
