# GDScript 代码规范

本页只维护项目风格差异。节点职责与 Resource 边界见 [Godot 开发约定](Godot开发约定.md)，
运行时接口见 [技术架构](技术架构.md)。局部修改沿用现有风格，不要求重排整个文件。

## 命名与类型

- 类名、节点名使用 PascalCase；函数、变量、信号以及 `.gd`、`.tscn`、`.tres` 文件名使用 snake_case；常量和枚举值使用 CONST_CASE。
- 代码标识符使用英文；项目文本和注释使用中文。
- 函数参数、返回值和信号参数标注类型。类型明确的局部值可用 `:=`；节点查询、Dictionary／Variant 读取等边界使用明确类型。
- 信号使用 `.emit()` 发射。连接与跨场景协调遵循 Godot 开发约定。

## 排版与说明

- 使用 Tab 缩进；函数间保留一个空行；单行以 100 字符为默认上限，无法自然拆分的资源路径和文案可例外。
- 公共接口中的非直观单位、状态所有权、副作用和算法约束用中文说明；不要求每个 getter 或回调补注释。
- 可配置数据的放置规则只在 Godot 开发约定维护，不把固定算法阈值一律搬到资源。
- 动态资源发现或外部输入边界验证资源类型；已保证类型的内部路径不重复添加类型检查。
- 运行问题通过 `push_error()`／`push_warning()` 报告；普通开发调试与测试输出可用 `print()`，正式诊断协议见技术架构。

## 工具覆盖

`tests/project_conventions_test.tscn` 已检查文件命名、旧式字符串发信号、函数返回类型等
低误伤规则；它不是完整 formatter 或 linter，未覆盖的风格仍按本页与附近代码保持一致。
不因一次局部修改而迁移全仓库警告或统一格式。

语言本身的语法以 [Godot GDScript 文档](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/index.html)
为准；本页不维护旧版本限制清单。
