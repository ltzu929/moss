# GDScript 代码规范 - MOSS模拟器项目

本文档只维护 GDScript/Godot 代码风格、类型标注、注释规范和实现层注意事项。运行时架构见 `技术架构.md`，测试技巧见 `测试指南.md`。

> 参考官方 GDScript 风格指南，适配本项目需求

---

## 一、命名规范

### 1.1 基本规则

| 类型 | 命名风格 | 示例 |
|------|----------|------|
| **类名** | PascalCase | `SectorData`, `GameEvent`, `EventOption` |
| **函数名** | snake_case | `load_events_from_disk()`, `get_average_authority()` |
| **变量名** | snake_case | `current_year`, `avg_authority`, `total_count` |
| **常量** | CONST_CASE | `MAX_YEAR = 2075`|
| **信号** | snake_case | `game_ended`, `option_selected` |
| **枚举** | PascalCase | `enum GameState { Running, Paused, Ended }` |
| **枚举值** | CONST_CASE | `GameState.RUNNING` |

### 1.2 节点命名

- 节点名称使用 PascalCase：`SectorInfoAsia`, `EventPopup`
- 唯一节点使用 `%` 唯一名称访问：`%YearLabel`, `%EventPopup`

### 1.3 文件命名

- 脚本文件：snake_case.gd → `main_os.gd`, `sector_info.gd`
- 场景文件：snake_case.tscn → `event_popup.tscn`
- 资源文件：snake_case.tres → `sector_asia.tres`, `event_2044.tres`

## 二、代码组织

### 2.1 文件结构顺序

每个 .gd 文件按以下顺序组织：

```
01. class_name 定义（如果需要）
02. extends 继承声明
03. 信号定义区域
04. 导出变量区域 (@export)
05. 常量/枚举区域
06. 成员变量区域
07. 生命周期函数 (_ready, _process, _input 等)
08. 公共函数（供外部调用）
09. 私有函数/回调函数（内部使用，以 _ 开头）
```

### 2.2 区域分隔

使用统一的分隔注释标记不同功能区域：

```gdscript
# ============================================================
# 信号定义
# ============================================================

signal game_ended(result: String)

# ============================================================
# 导出变量
# ============================================================

@export var all_events: Array[GameEvent]
```

## 三、注释规范

### 3.1 文档注释

使用 `##` 开头，描述函数的用途、参数和返回值：

```gdscript
## 从硬盘目录加载所有事件资源文件
## 自动扫描 res://data/events/ 下的 .tres 文件
## 无需返回值，直接填充 all_events 数组
func load_events_from_disk() -> void:
```

### 3.2 行内注释

使用 `#` 解释复杂逻辑：

```gdscript
# 类型安全检查：防止加载非事件资源
if event is GameEvent:
    all_events.append(event)
```

### 3.3 注释语言

- **本项目统一使用中文注释**
- 文档注释和行内注释均使用中文

## 四、类型标注

### 4.1 函数签名

所有函数必须标注参数和返回值类型：

```gdscript
# 推荐
func apply_consequences(
    event_name: String,
    order_delta: int,
    hope_delta: int
) -> void:
    ...

# 不推荐
func apply_consequences(event_name, order_delta, hope_delta):  # 缺少类型
```

### 4.2 变量声明

优先使用类型推断（`:=`）或显式类型声明：

```gdscript
# 推荐：类型推断
var path := "res://data/events/"
var sectors := %SectorInfoContainer.get_children()

# 推荐：显式类型
var current_year: int = 2044
var is_game_over: bool = false

# 不推荐：无类型
var path = "res://data/events/"  # 类型不明确
```

## 五、信号规范

### 5.1 信号定义

信号参数必须标注类型：

```gdscript
# 推荐
signal game_ended(result: String, message: String)
signal option_selected(index: int)

# 不推荐
signal game_ended(result, message)  # 无类型标注
```

### 5.2 信号发射

使用 `.emit()` 显式发射：

```gdscript
game_ended.emit("failed", "控制权丧失")
option_selected.emit(0)
```

### 5.3 信号连接

优先使用 `.connect()` 直接连接：

```gdscript
restart_btn.pressed.connect(_on_restart_pressed)
```

## 六、错误处理

### 6.1 错误报告

使用 `push_error()` 和 `push_warning()` 替代 `print()`：

```gdscript
# 错误（严重问题）
push_error("找不到板块: " + event_name)

# 警告（潜在问题）
push_warning("事件目录不存在: " + path)

# 调试信息（开发阶段）
print("加载事件: " + file_name)
```

### 6.2 类型检查

使用 `is` 进行类型安全检查：

```gdscript
if event is GameEvent:
    all_events.append(event)

if sector.get("data_card") != null:
    ...
```

## 七、代码风格

### 7.1 缩进与空格

- 使用 Tab 缩进（Godot 默认）
- 函数参数换行时对齐：

```gdscript
func apply_consequences(
    event_name: String,
    order_delta: int,
    hope_delta: int,
    energy_cost: int
) -> void:
```

### 7.2 空行规范

- 函数之间保留一个空行
- 区域分隔注释前后保留一个空行
- 逻辑块之间可适当添加空行提高可读性

### 7.3 行长度

- 单行代码不超过 100 字符
- 过长代码适当换行

## 八、本项目特殊约定

### 8.1 语言偏好

| 部分 | 语言 |
|------|------|
| 注释、文档 | 中文 |
| 调试信息 | 中文 |
| UI显示文本 | 中文 |
| 事件数据内容 | 中文 |
| 代码标识符 | 英文 |

### 8.2 数据驱动原则

- 游戏数据（板块、事件）优先使用 .tres 资源文件
- 避免在代码中硬编码数值
- 使用编辑器 Inspector 面板配置数据

### 8.3 场景文件注意事项

- 场景结构优先通过 Godot 编辑器或 Godot MCP 创建和配置
- 必要时可以谨慎编辑 `.tscn`，但必须保持资源引用、节点路径和唯一节点名称有效
- 手动修改场景后必须重新加载场景并运行相关测试
- 适合运行时生成的 UI 可以使用代码创建

## 九、GDScript 4.x 注意事项

### 9.1 常量类型限制

`const` 只支持基础类型和未类型化数组/字典。复杂类型用 `var` + 类型标注。

```gdscript
# 不允许
const INITIAL_AUTHORITIES: Dictionary = {"亚洲": 24, "北美": 26}

# 推荐
var _initial_authorities: Dictionary = {"亚洲": 24, "北美": 26}
```

### 9.2 节点路径检查

`has_node()` 不使用 `^` 唯一名前缀。

```gdscript
# 不允许
has_node("^Timer")

# 推荐
has_node("Timer")
has_node("%UniqueName")
```

### 9.3 Resource 类型检查

加载 `.tres` 资源后使用 `is` 做类型检查。

```gdscript
# 推荐
if event is GameEvent:
	all_events.append(event)

# 不推荐
if event as GameEvent:
	all_events.append(event)
```
