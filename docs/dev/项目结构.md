# 项目结构（待更新）

本文档只维护项目目录结构、关键文件职责和资源放置约定。开发阶段进度见 `开发流程.md`，运行时架构见 `技术架构.md`。

## 目录总览

```text
res://
├── data/
│   ├── sector_*.tres     # 板块数据 (.tres) - 7个板块
│   ├── commands/         # 指令配置 (.tres)
│   ├── events/           # 事件数据 (.tres) - 6个活动编年史事件
│   └── evolution/        # 进化能力数据 (.tres)
├── scripts/
│   ├── resources/        # 数据类 (Resource)
│   ├── systems/          # 核心系统脚本
│   ├── ui/               # 界面逻辑
│   └── utils/            # 工具函数
├── scenes/
│   ├── main_os.tscn      # 主场景（3列网格 + 右侧面板布局）
│   ├── event_popup.tscn
│   ├── sector_info.tscn
│   ├── year_progress.tscn
│   ├── moss_status_panel.tscn
│   └── game_over.tscn
├── tests/
│   ├── test_runner.gd
│   └── test_runner.tscn
├── docs/
└── assets/
```

## 放置约定

- 游戏配置数据优先放在 `data/` 下，以 `.tres` Resource 形式维护。
- 核心逻辑放在 `scripts/systems/`，数据类放在 `scripts/resources/`，界面逻辑放在 `scripts/ui/`。
- 场景文件放在 `scenes/`，不要手动编辑 `.tscn`。
- 自动化测试入口放在 `tests/`，测试运行方式见 `测试指南.md`。
- 设计、规范、流程、素材放在 `docs/`，按根 `CLAUDE.md` 的文档索引查阅。
