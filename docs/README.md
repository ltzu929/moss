## 各目录维护什么

- `design/`：已确认的游戏规则。事件结构、科技效果、数值与 UI 分别在各自文档维护。
- `lore/`：来源规则、原作文本和按年代组织的素材。素材不自动等于已实现剧情。
- `worldbuilding/`：设定主题索引、证据、游戏映射及未决问题。`canon/` 是目录名称，不代表里面每一条都是正史。
- `dev/`：开发顺序、架构、工程约定和验证记录。

扩写先核对来源和已有承载点，再明确玩家取舍及后果；候选进入正式设计需要相应设计授权，当前任务已明确批准的方向不重复确认。候选点子留在世界观映射中；节点效果只在科技树设计中维护，来源分级只在 lore 的规则文档中维护。

新增世界观只采纳已核对的一手资料，同人创作不采纳；Wiki 与解析记录是回查入口，不是直接扩写授权。原著与电影的阶段、数量及事件结局分开维护。
