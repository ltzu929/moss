# MOSS 世界观资料库说明

这套资料库用于把既有世界观资料结构化，服务后续事件、科技、指令、结局和 AI 协作。`docs/worldbuilding` 不制定新的来源规则，也不取代 `docs/lore`。

全项目导航见 [docs/README](../README.md)。准备扩写时，优先使用[游戏系统世界观映射](游戏系统世界观映射.md)的“事件与科技扩写准备”表，先找到已有内容的承载点。

## 权威关系

- `docs/lore/世界观资料来源与设定分级.md` 是唯一来源规则文档。
- `docs/worldbuilding` 只负责结构化整理、游戏系统映射、缺口和冲突记录。
- 解析视频字幕统一归入既有来源体系中的 `可靠二手整理`。仅凭解析视频字幕不得写成 `电影明确`。
- 游戏新增或重排内容继续使用既有体系中的 `游戏桥接`，并注明服务的玩法或叙事问题。

## 资料来源层级

新增或维护设定时，沿用 `docs/lore/世界观资料来源与设定分级.md` 的来源层级，包括但不限于：

- 电影明确
- 原著明确
- 官方/主创补充
- 可靠二手整理
- 游戏桥接
- 待核实

以上简称与权威规则中的完整名称对应。`canon/` 同时收录二手转述、推断和游戏映射，目录名不是证据等级；逐条读来源标记。

本目录不会再建立新的字母分级体系。

## 内容判断类型

对 `可靠二手整理`，尤其是解析视频字幕，额外记录内容判断类型：

- 画面信息转述：视频作者声称画面、字幕、界面或新闻中可见的信息。
- 强推断：视频作者基于多个画面、台词或时间关系的较可靠归纳。
- 弱推断：象征解读、个人观点、过度解读或证据不足的猜测。

```markdown

- 内容判断类型：
- 依据：
- 网络来源 URL、访问日期与页面位置（网络资料必填）：
- 原字幕位置或项目文件：

- 可能用途：
- 备注：
```

如果资料不是解析视频，`内容判断类型` 可以省略，但 `资料来源层级` 必须保留。

## 使用顺序

AI 或开发者处理世界观任务时建议先读：

1. `世界观总纲.md`
2. `MOSS现有设定概览.md`
3. `设定冲突与待确认事项.md`
4. 与任务相关的 `canon/*.md`
5. 需要回查来源时再读 `sources/流浪地球2解析整理.md`、本地原始字幕和 `docs/lore/`。

原始 SRT 是本地资料，不纳入仓库。仓库通过 `.gitignore` 排除 `docs/worldbuilding/sources/*.srt`；如需复核字幕位置，应在本地同目录放置原始字幕文件后再回查。

## 正式与候选边界

- 已采用内容：当前实现和已确认设计分别标注；其中游戏桥接仍是游戏改编，不能称为原作正史。
- 原作依据：是否能作为硬设定只由来源规则和单项证据决定，不能从“游戏里已经有”反推。
- 候选方案：可靠二手整理中的强推断、未进入游戏实现的扩写建议。
- 待确认事项：弱推断、解析视频争议、游戏原创重大设定、文档与代码冲突。

写事件或结局时，应先确认资料来源层级，再决定是否进入正式剧情。不要把“可能是 MOSS 操控”写成“MOSS 已确认操控”。


## 本地 Wiki 资料与文档维护

`source` 资料先保留来源与站内标记，再把简短结论放入对应 `canon/` 主题；具体事件和科技候选只在[系统映射](游戏系统世界观映射.md)维护。原始全文位于被 Git 忽略的 `sources/unitedearth-cache/`，不要复制进正式设定文档。当前抓取范围与结果见[完整索引](sources/联合地球百科索引.md)。

本轮重点阅读了事件、编年史、科技设施和计划；其余条目已经抓取并建立分类索引，但未逐条验证原始出处。未确认的候选不改写已确认游戏规则。
