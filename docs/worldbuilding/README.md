# MOSS 世界观资料库说明

这套资料库用于把《流浪地球》电影明确设定、解析视频推断和 MOSS 游戏原创内容分层保存，供后续事件、科技、指令、结局和 AI 协作读取。它补充 `docs/lore/` 的旧素材库，但不删除或替代现有文档。

## 文件职责

| 文件 | 职责 |
|---|---|
| `../流浪地球2解析整理.md` | 从完整 SRT 中抽取《流浪地球2》世界观条目，保留字幕序号和时间码。 |
| `世界观总纲.md` | 给开发者和 AI 快速理解项目定位、时间范围、核心矛盾和未决问题。 |
| `canon/时间线.md` | 整理 2044-2075 年关键节点、来源等级、后果和游戏覆盖情况。 |
| `canon/组织与派系.md` | 整理联合政府、移山支持者、数字生命派、军事安全和民间力量。 |
| `canon/科技与设施.md` | 整理行星发动机、月球发动机、太空电梯、550 系列、地下城等设施。 |
| `canon/社会与民生.md` | 整理地下城资格、资源分配、工作教育、难民、抗议和舆论。 |
| `canon/数字生命与MOSS.md` | 分开记录数字生命、550 系列、MOSS 已确认能力、推测能力和游戏原创。 |
| `canon/人物与关键行动.md` | 只记录会影响世界局势的人物及行动，不写百科。 |
| `MOSS现有设定概览.md` | 基于当前仓库文档、脚本和 `.tres` 资源整理游戏已有设定。 |
| `游戏系统世界观映射.md` | 把时间、事件、科技、指令、地区、资源、结局等机制映射到世界观解释。 |
| `世界观缺口清单.md` | 按 P0-P3 记录当前游戏世界观缺口和推荐处理方式。 |
| `设定冲突与待确认事项.md` | 记录原作不确定、视频争议、游戏与电影/文档/代码冲突和作者需决定的问题。 |

## 来源等级

- A：原作明确设定。来自电影台词、字幕明确陈述、画面直接展示。可以作为正式原作设定使用。
- B：强推断。来自解析视频对多个画面、台词和时间关系的较可靠归纳。可以作为同人创作依据，但必须标记为推断。
- C：弱推断或作者观点。来自象征解读、个人判断或证据不足的猜测。只能作为灵感。
- D：MOSS 游戏原创设定。为游戏节奏、机制或剧情补缀新增，不得与 A 冲突。

判断不清时降低等级。任何非 A 内容都不得写成电影官方事实。

## 新增设定格式

新增条目优先使用以下字段：

```markdown
### 编号 标题

- 时间：
- 地点：
- 涉及人物或组织：
- 设定内容：
- 来源等级：A / B / C / D
- 依据：
- 原字幕位置或项目文件：
- 与 MOSS 游戏的关系：
- 可能用途：
- 备注：
```

## 使用顺序

AI 或开发者处理世界观任务时建议先读：

1. `世界观总纲.md`
2. `MOSS现有设定概览.md`
3. `设定冲突与待确认事项.md`
4. 与任务相关的 `canon/*.md`
5. 需要回查来源时再读 `../流浪地球2解析整理.md` 和旧 `docs/lore/` 文档。

## 正式与候选边界

- 正式设定：A 类原作事实、当前仓库已实现内容、经项目作者确认的 D 类游戏原创。
- 候选方案：B 类强推断、未进入游戏实现的扩写建议。
- 待确认事项：C 类解释、解析视频争议、游戏原创重大设定、文档与代码冲突。

写事件或结局时，应先确认来源等级，再决定是否进入正式剧情。不要把“可能是 MOSS 操控”写成“MOSS 已确认操控”。
