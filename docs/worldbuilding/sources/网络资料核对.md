## 本次不采用的结论

- WEB-02 将丫丫上传与月球发动机爆炸写成直接因果，并对 MOSS 的时间感知和终极意图作确定性解释。它们不能仅凭百科成为游戏硬设定，分别进入 [CFM-012 与 CFM-013](../设定冲突与待确认事项.md)。
- WEB-04 出现月球资源与发动机能源的设定描述；本次不据此统一两部电影与原著的燃料体系，不制定开采产量或能源兑换数值。
- 美术文中摄影棚面积、道具重量、场景座位数是制作资料，不能直接写成世界观内的设施容量。
- WEB-01 已取得正文，但页面混有同人扩展与未经独立核实的细节；可访问不等于内容已核验。

## WEB-01 全站主命名空间资料

首批 12 个页面的试读已扩大为主命名空间完整抓取。覆盖数量、全部固定修订链接、站内提示和复用方式统一维护在[联合地球百科索引](联合地球百科索引.md)，不在这里维护第二份条目清单。

- 原始 HTML、提取正文及逐页元数据已从临时试读方式转为项目本地 `unitedearth-cache/` 缓存；它已被 Git 忽略。
- 可复用工具为项目根目录 `tools/fetch_worldbuilding_wiki.py`。本次目录列出的 180 个非重定向页面全部取得正文，47 个别名保留在目录元数据。
- 其中 100 页带同人/虚构提示，7 页带推测提示；没有提示的页面也不是默认可信。完整抓取与逐项原始出处核验是不同状态。
- 本机默认 urllib 请求曾返回 403，显式设置 User-Agent 后成功；这是已观察到的请求差异，不足以断定网站具体拦截规则。侧边栏正文读取仍未恢复验证。
