## 资料位置与复用

- 抓取工具：[fetch_worldbuilding_wiki.py](../../../tools/fetch_worldbuilding_wiki.py)。需要 Python 和 `beautifulsoup4`；本次使用环境已有依赖。
- 在项目根目录执行 `python tools/fetch_worldbuilding_wiki.py`：顺序抓取，每次间隔 1 秒，不下载图片，不使用登录凭据；错误写入清单并以非零状态退出，不自动重试。
- 原始资料位于本目录的 `unitedearth-cache/`：`directory.json` 保存包含别名的完整目录，`manifest.json` 保存逐页状态、URL、修订号、分类、标记、链接与结构化脚注，`pages/` 保存 HTML 和 TXT。
- 本地缓存已加入 `.gitignore`，避免把第三方全文带入代码仓库。文档保留本索引、固定修订链接和自行概括的设定用途；缓存丢失可重跑，但会取得网站当时的新版本。
- 没有结构化脚注不等于完全无出处；参考书目可能以普通段落出现，需看正文。未读取原书的引用仍是 Wiki 二手转述。
- 首页显示的授权为 CC BY-NC-SA 3.0 中国大陆；图片及引用材料的具体权利另依各自来源。原始资料不等于本项目原创内容。
