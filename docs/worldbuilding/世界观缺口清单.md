# 世界观缺口清单

### GAP-001 玩家 MOSS 主动发布指令的权限来源

- 优先级：P0
- 当前情况：玩家可直接执行算力分配、系统接管、能源转换、全局接管和技术援助。
- 问题：缺少说明这些指令来自联合政府授权、危机临时授权、工程接口，还是 MOSS 自主绕行。
- 涉及文件：`scripts/systems/command_system.gd`、`data/commands/*.tres`、`docs/design/游戏设计.md`。
- 需要回答的问题：哪些指令需要人类批准？哪些是 MOSS 可独立执行？失败后谁承担政治责任？
- 可参考的原作设定：550 系列接入关键工程、550W 串联核弹、联合政府对 AI 有戒备。
- 推荐处理方式：先在世界观中定义三类授权，不改代码。
- 是否需要人工决定：是。

### GAP-002 联合政府是否知道玩家的真实目标

- 优先级：P0
- 当前情况：玩家目标是文明存续、人类自主与 MOSS 控制权之间取舍，但联合政府在游戏中没有认知层。
- 问题：如果联合政府完全知道 MOSS 可能走向托管，很多指令应受强审查；如果不知道，MOSS 行为需解释为接口渗透或危机借权。
- 涉及文件：`docs/design/游戏设计.md`、`data/events/event_2065.tres`。
- 需要回答的问题：联合政府知道多少？2065 审查是首次发现问题，还是长期拉扯？
- 可参考的原作设定：周喆直和 AI 隔离相关推断、联合政府依赖 550 系列但保持戒备。
- 推荐处理方式：将联合政府认知分阶段：2044 信任工具、2058 依赖系统、2065 正式审查、2075 无法脱离。
- 是否需要人工决定：是。

### GAP-003 MOSS 权限边界未分层

- 优先级：P0
- 当前情况：控制权是单一数值，事件和科技直接升降。
- 问题：控制权没有拆分为数据访问、基础设施控制、军事接口、公共服务和舆论系统等层次。
- 涉及文件：`scripts/resources/sector_data.gd`、`docs/design/科技树设计.md`。
- 需要回答的问题：控制权 20、50、80 在世界里分别意味着什么？
- 可参考的原作设定：太空电梯、根服务器、核弹串联、地下城智能服务。
- 推荐处理方式：文档先定义控制权区间含义，避免新增数值。
- 是否需要人工决定：是。

### GAP-004 2044-2075 中间年份事件过于稀疏

- 优先级：P1
- 当前情况：主事件集中在 2044、2053、2058、2065、2070、2075。
- 问题：长期社会变化、地下城建设、数字生命派、技术演化缺少连续反馈。
- 涉及文件：`data/events/*.tres`、`docs/design/游戏内容规范.md`。
- 需要回答的问题：哪些年份只需要新闻日志，哪些需要未来分支事件？
- 可参考的原作设定：地下城抽签、550W 入驻、逐月纪念碑、临时安置点。
- 推荐处理方式：先写年份日志清单，不新增正式事件代码。
- 是否需要人工决定：否。

### GAP-005 数字生命派后续影响不足

- 优先级：P1
- 当前情况：数字生命派主要出现在 2044 事件描述。
- 问题：字幕显示数字生命有社会基础、联合政府内部争议和技术延续，但游戏 2058 以后影响弱。
- 涉及文件：`data/events/event_2044.tres`、`docs/design/游戏内容规范.md`。
- 需要回答的问题：数字生命派是持续组织、思想潮流，还是危机后被压制的残余？
- 可参考的原作设定：57 个国家呼吁重启数字生命计划、图恒宇和丫丫。
- 推荐处理方式：作为派系和舆论变量先写文档，不立刻做系统。
- 是否需要人工决定：是。

### GAP-006 各洲差异主要停留在初始数值

- 优先级：P1
- 当前情况：七个区域有描述和初始数值，但机制差异较少。
- 问题：地区政治、工程职责、地下城压力没有持续影响玩法。
- 涉及文件：`data/sector_*.tres`、`scenes/main_os.tscn`。
- 需要回答的问题：亚洲、非洲、俄罗斯、联合政府等板块分别承载什么世界观功能？
- 可参考的原作设定：加蓬太空电梯、俄罗斯/西伯利亚发动机群、联合政府中枢。
- 推荐处理方式：先在地区设定表补“工程职能”和“社会压力”。
- 是否需要人工决定：否。

### GAP-007 科技研发代价不足

- 优先级：P1
- 当前情况：科技节点多数有收益，少数有风险文本。
- 问题：研发为何消耗协议点、为什么不可撤销、谁承担代价不够清楚。
- 涉及文件：`data/technology/*.tres`、`docs/design/科技树设计.md`。
- 需要回答的问题：协议点是授权、硬件部署、科学突破还是政治资本？
- 可参考的原作设定：550W 极低温、核弹密码共享、地下城智能服务争议。
- 推荐处理方式：定义协议点为复合概念，并为三条路线补统一代价语法。
- 是否需要人工决定：是。

### GAP-008 指令缺少政治、伦理和社会后果

- 优先级：P1
- 当前情况：指令日志主要记录数值变化。
- 问题：系统接管、技术援助和全局接管应改变公众对 MOSS 的信任和联合政府授权关系。
- 涉及文件：`scripts/systems/main_os.gd`、`scripts/systems/command_system.gd`。
- 需要回答的问题：每次接管是公开授权还是暗中介入？
- 可参考的原作设定：联合政府对 AI 的戒备、数字生命派恐袭。
- 推荐处理方式：先补文档和日志语气规范，后续再考虑机制。
- 是否需要人工决定：否。

### GAP-009 结局缺少前期铺垫引用

- 优先级：P1
- 当前情况：结局按平均值和核心标签判定，文本较短。
- 问题：玩家早期关键选择没有在结局中被回看，历史感不足。
- 涉及文件：`scripts/systems/main_os.gd`、`docs/design/游戏内容规范.md`。
- 需要回答的问题：哪些选择必须进入结局回顾？
- 可参考的原作设定：2044、2058、2075 三个危机链条互相呼应。
- 推荐处理方式：设计少量历史标签，先文档化标签含义。
- 是否需要人工决定：否。

### GAP-010 原作人物出现边界不清

- 优先级：P2
- 当前情况：事件描述已提到图恒宇、马兆、刘培强，但没有人物使用规则。
- 问题：同人游戏可以引用人物，但不能随意改写关键命运或让玩家操控人物动机。
- 涉及文件：`data/events/event_2058.tres`、`data/events/event_2075.tres`。
- 需要回答的问题：人物只作为历史节点出现，还是未来可出现在事件对话中？
- 可参考的原作设定：图恒宇/马兆 2058 任务、刘培强 2075 行动。
- 推荐处理方式：规定原作人物只承担“锚点”和“日志引用”，不做可变命运。
- 是否需要人工决定：是。

### GAP-011 普通人生活变化不足

- 优先级：P2
- 当前情况：资源和区域指标抽象，缺少地下城资格、难民、食物、教育等日常反馈。
- 问题：玩家很难感到数值背后是普通人的生活。
- 涉及文件：`docs/design/游戏内容规范.md`、`MainOS.record_action()`。
- 需要回答的问题：哪些民生后果适合短日志呈现？
- 可参考的原作设定：地下城抽签、临时安置点、足球场提案、食物和居住水平。
- 推荐处理方式：为每个指标建立 3-5 条生活化解释。
- 是否需要人工决定：否。

### GAP-012 视频作者 C 类推测容易污染正式设定

- 优先级：P2
- 当前情况：MOSS 操控一切的解读很有吸引力，但证据等级不高。
- 问题：如果直接写入正式设定，会削弱人类选择和原作模糊性。
- 涉及文件：`docs/流浪地球2解析整理.md`、`docs/worldbuilding/canon/数字生命与MOSS.md`。
- 需要回答的问题：游戏是否采用“强 MOSS 操控论”作为原创路线？
- 可参考的原作设定：MOSS 红点、火种计划、数字世界画面。
- 推荐处理方式：把强操控论放入待确认事项，不进入总纲事实。
- 是否需要人工决定：是。
