# MOSS 现有设定概览

本页是当前实现的阅读入口，不另行维护数值、资源清单或验收结果。2026-09-13 按当前权威设计和磁盘资源更新；本次仅核对文档，未运行游戏。

## 当前游戏

玩家从 550C、550W 逐步演化为 MOSS，在 2044 至 2075 年间调度区域、资源和科技，处理危机并走向四类治理结局。定位和玩法见[游戏设计](../design/游戏设计.md)，交互与存档见[UI 交互规范](../design/UI交互规范.md)。

当前固定历史为五个危机阶段：2044 太空电梯、2058 北京联网救援与最终支援、2075 发动机救援与木星危机最终支援。四个核心决策键供后续事件和结局读取；同月阶段按顺序处理。完整资源、数值和读取关系以[游戏内容规范](../design/游戏内容规范.md)为准。

旧 2053、2065、2070 事件、17 个中型事件和两条条件分支已经退出。保留的通用事件状态与条件接口不表示旧内容仍在运行。旧存档的版本处理也见游戏内容规范。

| 科技与指令 | 三条科技路线及协议点、部署含义、指令效果见[科技树设计](../design/科技树设计.md)。游戏节点不能作为原作技术事实。 |
| 区域与资源 | 六个区域板块及算力、能源、秩序、希望、控制权规则见[游戏设计](../design/游戏设计.md)。联合政府作为组织存在，不是独立区域卡。 |
| 局势 | 持续影响区域与资源的游戏机制；题材与固定历史边界见[游戏设计](../design/游戏设计.md)。 |
