# 社会与民生

## 地下城资格

- 设定内容：地下城名额采用抽签，解析字幕转述画面中出现多次抽签结果、抽签次数和未通过抽签者禁止进入地下城基地的标识。
- 资料来源层级：可靠二手整理。
- 内容判断类型：画面信息转述。
- 游戏关系：当前 `SectorData.population` 只有人口总量，没有地下城资格、等待队列或未中签人群。

## 人口筛选

- 设定内容：航天员资格、永久航天员紧急入驻标准、地下城抽签和人口数据采集共同构成人口筛选体系。
- 资料来源层级：可靠二手整理。
- 内容判断拆分：
  - 画面信息转述：航天员资格、永久航天员紧急入驻标准、地下城抽签和人口数据采集共同出现。
  - 强推断：这些机制共同构成人口筛选体系。
- 游戏关系：可解释“控制权”不仅是系统权限，也涉及 MOSS/550 系列是否介入人口数据和资格分配。

## 资源分配

- 设定内容：船票、地下城名额、发动机坝体临时安置、食物和居住水平是危机时期的核心资源分配问题。
- 资料来源层级：可靠二手整理。
- 内容判断拆分：
  - 画面信息转述：船票、地下城名额、发动机坝体临时安置、食物和居住水平构成资源压力画面。
  - 强推断：这些问题共同构成危机时期的核心资源分配矛盾。
- 游戏关系：当前“能源”和“算力”有机制含义，但食物、住所、医疗、地下城容量尚未被世界观化。

## 工作与教育

- 设定内容：行星发动机早期大量采用人工建设，作者推断是为了减少自动化失业和社会动荡；地下城中教育文件和长期旅程精神设施有画面线索。
- 资料来源层级：可靠二手整理。
- 内容判断类型：强推断。
- 游戏关系：科技研发需要体现就业、教育和社会适应代价，否则“自动化升级”只像纯数值收益。

## 移民和难民

- 设定内容：地下城进水导致无家可归者暂住发动机坝体临时安置点，未通过抽签者被限制进入地下城基地。
- 资料来源层级：可靠二手整理。
- 内容判断类型：画面信息转述。
- 游戏关系：区域差异可以从“工程核心区、临时安置点、地下城资格压力”扩写，而不只是数值不同。

## 社会抗议

- 设定内容：2044 年利伯维尔等地有民众抗议、冲突和对太阳危机真实性的质疑；反对行星发动机和崇尚自然主义等标语出现。
- 资料来源层级：可靠二手整理。
- 内容判断拆分：
  - 画面信息转述：2044 年利伯维尔等地有民众抗议、冲突和对太阳危机真实性的质疑。
  - 强推断：公众不信任联合政府或 MOSS 会直接影响希望和秩序。
- 游戏关系：希望和秩序可以承载抗议强度，但事件应说明公众为何不信任联合政府或 MOSS。

## 数字生命支持者的社会基础

- 设定内容：昂贵方舟船票、移山计划风险、地下城资格不确定和现实生存压力，为数字生命路线提供社会基础。
- 资料来源层级：可靠二手整理。
- 内容判断类型：强推断。
- 游戏关系：数字生命派已通过 MID-03、MID-09、MID-12、MID-16 组成的数字生命暗流链进入中型事件和后续回声，但仍没有独立派系状态或组织化影响机制。

## 普通人对联合政府的态度

- 设定内容：民众既依赖联合政府组织工程和地下城，也会质疑太阳危机、反对发动机、担心资格分配不公。
- 资料来源层级：可靠二手整理。
- 游戏映射层级：游戏桥接仅用于解释 `data/sector_europe.tres` 中欧洲势力治理中枢部分的数值含义。
- 内容判断拆分：
  - 画面信息转述：民众既依赖联合政府组织工程和地下城，也会质疑太阳危机、反对发动机和担心资格分配。
  - 强推断：欧洲势力板块的希望较低、秩序较高可部分解释为“中枢稳定但人心承压”。
- 游戏关系：欧洲势力板块合并承载治理中枢与高纬度发动机群压力，见 `data/sector_europe.tres`。

## 灾难时期的信息传播和舆论

- 设定内容：新闻频道、泄露录像、会议消息、手机抽签结果和各国媒体共同构成舆论场；作者推断黑客公开内部录像可引导民众冲击移山/逐月计划。
- 资料来源层级：可靠二手整理。
- 内容判断拆分：
  - 画面信息转述：新闻频道、泄露录像、会议消息、手机抽签结果和各国媒体共同构成舆论场。
  - 强推断：黑客公开内部录像可引导民众冲击移山/逐月计划。
- 游戏关系：日志/新闻系统可承担世界观反馈，不应只记录数值变化。
