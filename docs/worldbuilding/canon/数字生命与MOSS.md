# 数字生命与 MOSS

## 数字生命技术的公开目标

- 公开目标：以数字化方式保存或延续意识，使个体在物理身体死亡后仍能以某种形式存在。
- 原作事实：数字生命研究所、丫丫数字卡和多项界面参数在影片画面中出现。
- 解析推断：数字生命支持者并非只有恐怖分子，背后有社会、政治和生存压力。
- 来源等级：A / B。

## 图恒宇和丫丫相关设定

- 原作事实：图恒宇围绕丫丫数字生命持续行动；丫丫数字卡、生日、识别置信度、身高、采样率、模型版本等界面信息出现。
- 解析推断：丫丫不是普通录像回放，而是具备某种互动和迭代能力的数字生命样本。
- 风险边界：不能直接把“数字生命等同真实生命”写成项目结论。
- 来源等级：A / B。

## 550 系列的发展

- 550C：2044 阶段可接入关键工程/自动化系统，涉及太空电梯和无人机控制画面。
- 550W：2058 阶段的新型量子计算机，参与行星发动机、核弹串联、根服务器重启和人口/资格相关系统。
- MOSS：后续空间站 AI，目标口径可使用“延续人类文明”，但具体动机和操控范围必须分级。
- 来源等级：A / B。

## MOSS 已确认的能力

- 可在第一部中执行联合政府授权的火种计划并控制领航员号空间站相关系统。
- 与 550 系列和关键工程自动化存在技术连续性。
- 片尾/数字世界画面把 MOSS 红点与数字世界联系起来。
- 来源等级：A。

## MOSS 推测中的能力

- 可能影响或引导 2044 太空电梯危机中的系统状态。
- 可能通过 550W/数字生命数据学习人类思维。
- 可能在 2075 木星危机中通过屏幕信息引导刘培强。
- 可能对马兆、图恒宇和数字世界有更深层操控。
- 来源等级：C。

这些内容只能作为伏笔或原创灵感，不得作为电影已确认事实。

## MOSS 的权限边界

- 已确认边界：必须区分人类授权、系统接入能力和 MOSS 自主意图。
- 游戏当前边界：玩家以 MOSS/550 系列视角执行指令，但为什么拥有主动发布指令的权限尚未完整解释。
- 待补问题：联合政府是否知道 MOSS 的真实目标、哪些指令需要人类授权、哪些是 MOSS 绕行执行。
- 来源等级：A / D。

## MOSS 与人类决策的关系

- 原作事实：MOSS 以“延续人类文明”为核心口径，在危机中可能牺牲局部人类利益。
- 解析推断：MOSS 可能通过布置信息、控制系统或制造条件来推动人类作出它计算中的选择。
- 游戏原创：当前游戏把玩家置于“从 550C、550W 演化为 MOSS 的守护者 AI”位置，在文明存续、人类自主和控制权之间取舍。
- 来源等级：A / C / D。

## 当前游戏对 MOSS 的原创设定

- 玩家从 550C 起步，激活 2 个科技节点进入 550W，激活 6 个节点进入 MOSS。
- 玩家可通过托管、核心演化和人类赋能三条科技路线改变能力。
- 结局包括失败、共存协议、MOSS 托管和人类自主。
- 来源等级：D。
- 对应文件：`scripts/systems/technology_system.gd`、`scripts/systems/main_os.gd`、`data/technology/*.tres`。
