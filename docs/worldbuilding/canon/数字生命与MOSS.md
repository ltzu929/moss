# 数字生命与 MOSS

## 数字生命技术的公开目标

- 公开目标：以数字化方式保存或延续意识，使个体在物理身体死亡后仍能以某种形式存在。
- 可靠二手整理中的画面信息转述：数字生命研究所、丫丫数字卡和多项界面参数出现在解析字幕记录中。
- 可靠二手整理中的强推断：数字生命支持者并非只有恐怖分子，背后有社会、政治和生存压力。
- 使用边界：仅凭解析字幕不得把数字生命技术细节升级为电影明确。

## 图恒宇和丫丫相关设定

- 可靠二手整理中的画面信息转述：图恒宇围绕丫丫数字生命持续行动；丫丫数字卡、生日、识别置信度、身高、采样率、模型版本等界面信息出现。
- 可靠二手整理中的强推断：丫丫不是普通录像回放，而是具备某种互动和迭代能力的数字生命样本。
- 风险边界：不能直接把“数字生命等同真实生命”写成项目结论。

## 550 系列的发展

- 550C：解析字幕转述 2044 阶段 550C 与太空电梯、无人机和塔台系统相关。
- 550W：解析字幕转述 2058 阶段 550W 与行星发动机、核弹串联、根服务器重启和人口/资格相关系统有关。
- MOSS：后续空间站 AI，目标口径可使用“延续人类文明”，但具体动机和操控范围必须分级。
- 资料来源层级：可靠二手整理。
- 游戏映射层级：游戏桥接仅用于解释当前科技阶段，不作为原作事实。
- 内容判断拆分：
  - 画面信息转述：550C 与 2044 太空电梯、无人机和塔台系统相关；550W 与 2058 行星发动机、核弹串联、根服务器重启和人口/资格相关系统有关。
  - 强推断：550 系列的发展构成 MOSS 演化的技术背景。

## MOSS 已确认材料

- 既有 lore 文档把第一部中领航员号空间站 AI、火种计划和“延续人类文明”作为重要材料。
- 解析字幕转述片尾/数字世界画面把 MOSS 红点与数字世界联系起来。
- 资料来源层级：沿用 `docs/lore/世界观资料来源与设定分级.md`。
- 解析视频层级：可靠二手整理，仅用于补充回查线索。

- 可能影响或引导 2044 太空电梯危机中的系统状态。
- 可能通过 550W/数字生命数据学习人类思维。
- 可能在 2075 木星危机中通过屏幕信息引导刘培强。
- 可能对马兆、图恒宇和数字世界有更深层操控。
- 资料来源层级：可靠二手整理。
- 内容判断类型：弱推断。

这些内容只能作为伏笔或游戏桥接灵感，不得作为电影明确事实。

## MOSS 的权限边界

- 已确认边界：必须区分人类授权、系统接入能力和 MOSS 自主意图。
- 游戏当前边界：玩家以 MOSS/550 系列视角执行指令，权限采用分阶段授权模型；指令按常规授权、危机授权和争议授权解释。
- 待补问题：三类授权还没有进入独立数据结构或日志系统，联合政府逐步察觉模型也没有独立认知层。
- 资料来源层级：游戏桥接。
- 参考材料层级：可靠二手整理，仅用于提示 AI 权限边界争议。

## MOSS 与人类决策的关系

- 既有项目设定：MOSS 以“延续人类文明”为核心口径，在危机中可能牺牲局部人类利益。
- 解析视频弱推断：MOSS 可能通过布置信息、控制系统或制造条件来推动人类作出它计算中的选择。
- 游戏桥接：当前游戏把玩家置于“从 550C、550W 演化为 MOSS 的守护者 AI”位置，在文明存续、人类自主和控制权之间取舍。
