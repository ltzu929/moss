# 名称与术语

本页统一项目写法，区分原著、电影资料、游戏名称及未核实异名。来源采纳门槛见[来源规则](../../lore/世界观资料来源与设定分级.md)。Wiki 重定向与消歧义只帮助检索，不能证明官方名称；同人名称不采纳。

## 有原文依据的称呼与区别

官方页面均于 2026-09-08 重读，发布者为“电影流浪地球”；段落定位见[网络资料核对](../sources/网络资料核对.md)。原著位置回查[科技与设施](科技与设施.md) NOV 编号。

| 项目写法 | 区分规则 | 一手依据 |
|---|---|---|
| 联合政府（UEG） / 联合国（UN） | 两种机构名称及缩写不互换；“联合地球百科”是资料站名称。项目已有“地球联合政府”用法不意味着采用该站组织架构。 | [WEB-05](https://www.gcores.com/articles/162106)“UN 标识和 UEG 标识设计对比”。 |
| 移山计划 / 逐月计划 / 方舟计划 | 地球推进主计划、月球配套计划与备用方案分别表述。 | [WEB-04](https://www.gcores.com/articles/161729)开头三项计划说明。 |
| 流浪地球计划 | 电影整体计划称呼；回顾早期项目可写“移山计划（后称流浪地球计划）”。具体更名日期另查时间线，不由别名推定。 | 既有电影口径；精确日期未重新核验。 |
| 领航员国际空间站 | 官方美术正文用名；项目简称“领航员号”可保留。方舟号是另一设施，不互相替换。 | [WEB-04](https://www.gcores.com/articles/161729)“领航员计划”标识及空间站段。“领航员计划”确见官方文，不能误判为虚构词，也不能等同于火种计划。 |
| 月球发动机 / 逐月卫星发动机 | 电影资料中的月球推进设施；不写成地球上的转向发动机。 | WEB-04“逐月卫星发动机主要结构”。 |
| 地球发动机、山、峰 | 小说用名；山与峰是小说中的两类发动机，不自动等于电影推进型与转向型。 | 原著 NOV-01。 |
| 550C / 550W / MOSS | 550C、550W 为计算平台称呼；MOSS 为相关 AI 称谓。游戏将三者设为成长阶段，不是原作的型号上市年表。 | WEB-04 的 550C 自动建造段、WEB-05 的 550W 段；MOSS 身份沿用既有电影依据。官方文中的起名猜测也不用于确立觉醒年份。 |
| 工程外骨骼 / 门框机器人 | 前者辅助人员作业，后者可作为救援供电设备；设备用途不等于自主决策权。 | WEB-05“工程外骨骼”与北京救援供电段。 |
| 中国互联网中心北京基地旧址 | 2058 北京救援地点采用这一明确限定；不能混写成北京航天中心或仍正常运行的新址。 | WEB-05 先遣一队出发与旧址救援段。 |
