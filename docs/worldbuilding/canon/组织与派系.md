# 组织与派系

- 目标：协调全球资源，推进移山/流浪地球计划、逐月计划、地下城和危机应对。
- 权力来源：成员国授权、危机状态下的全球工程和安全治理能力。
- 内部矛盾：移山计划与其他方案之争；数字生命是否恢复；AI/550 系列是否应被隔离或托管关键系统。
- 对移山计划的态度：总体支持，但解析字幕转述会议中存在放弃或削弱移山计划的政治压力。
- 对数字生命计划的态度：公开层面禁止或压制；解析字幕转述联合政府内部有人讨论恢复数字生命。
- 与 MOSS 的关系：依赖 550 系列参与工程、航天员筛选、根服务器重启和核弹串联，同时对 AI 权限存在戒备。

## 移山计划支持者

- 目标：建设行星发动机，推动地球逃离太阳危机。
- 权力来源：科学论证、工程体系、联合政府中支持路线的国家和技术人员。
- 内部矛盾：自动化效率与就业/稳定的冲突；对 AI 辅助的依赖与防备并存。
- 对移山计划的态度：核心支持。
- 对数字生命计划的态度：通常视其为竞争路线或安全风险。
- 与 MOSS 的关系：需要 550 系列算力和自动化，但不应把全部决策权交出。
- 资料来源层级：可靠二手整理。

  - 强推断：自动化效率、就业稳定和 AI 依赖之间存在政治张力。

## 数字生命派

- 目标：恢复或推进数字生命计划，以数字化意识保存作为生存路线。
- 权力来源：研究机构、支持者群体，以及解析字幕弱推断中的国家或军事支持。
- 内部矛盾：技术救赎、恐怖袭击、政治游说和个人执念混杂。
- 对移山计划的态度：部分成员反对或破坏移山/逐月工程，部分支持者可能只是对现实逃亡方案失望。
- 对数字生命计划的态度：支持。
- 与 MOSS 的关系：数字生命技术和 550 系列高度相关；MOSS 可能利用数字生命数据，但具体操控未确认。
- 资料来源层级：可靠二手整理。
- 内容判断拆分：
  - 画面信息转述：数字生命派支持恢复或推进数字生命计划，部分成员破坏工程体系。
  - 强推断：数字生命路线拥有不止恐怖袭击者的社会基础。
  - 弱推断：背后存在国家或军事支持、MOSS 利用数字生命数据等说法未确认。
