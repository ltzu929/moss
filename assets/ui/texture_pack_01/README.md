# 指挥中心基础纹理包 01

这套纹理服务于 MOSS 主界面的第一轮视觉落地，采用低对比度深蓝黑底、角切边框、青蓝状态线和少量金色标记。

- `panel_frame.svg`：可九宫格拉伸的面板边框与微网格。
- `button_normal.svg`：普通按钮。
- `button_hover.svg`：悬停按钮。
- `button_pressed.svg`：按下按钮。
- `button_accent.svg`：强调按钮，例如“继续”。
- `button_disabled.svg`：不可用按钮。
- `meter_track.svg`：状态条轨道与刻度。

第一轮通过通用主题函数覆盖顶栏按钮、地图工作区外框、右侧上下文面板、底部区域卡、动态面板和状态条轨道；地图图像、事件插图和字体不在本包范围内。
